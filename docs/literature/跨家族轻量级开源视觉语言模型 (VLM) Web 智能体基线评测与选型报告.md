# 2025–2026 跨家族轻量级开源视觉语言模型 (VLM) Web 智能体基线评测与选型报告

## 核心研究背景与基线设计逻辑分析

在当前视觉语言模型（Vision-Language Models, VLM）驱动的 Web 智能体研究领域，构建严谨的受控实验以剥离模型底层架构带来的统计学偏差，已成为评估模型真实泛化能力的关键环节。受控的 Web 智能体评测通常要求在一个固定的、非模型特定的脚手架（fixed scaffold）下运行，这就意味着智能体必须完全依赖其内置的跨模态对齐能力、空间位置感知能力以及严格的格式遵循能力，将视觉页面解析转化为统一 JSON 动作空间中的有效指令。在当前的基线矩阵中，B0（Qwen3-VL-235B-A22B）与 B1（Qwen3-VL-4B）已牢牢占据了基于 Qwen 架构体系的上限与下限锚点。然而，B2（Gemma3-4B-it）在 VisualWebArena 基准测试中出现了极为严重的“触底”现象（成功率维持在 ~1% 的极限水平），这表明该家族模型在处理未经特定领域微调（Agent-SFT）的纯零样本 Web 导航任务时，遭遇了不可逾越的能力断层。

为了验证受控实验结论是否具有真正的跨架构泛化能力，引入第四个基线模型（B3）变得至关重要。该基线不仅必须规避类似于 Gemma3-4B-it 的触底崩溃风险，还必须在底层文本生成引擎（LLM Backbone）上与 Qwen 家族划清界限。当前大量的轻量级视觉语言模型在视觉编码器上可能各有创新，但在语言解码器部分却高度依赖预训练更为成熟的 Qwen 权重，这种隐性的血统重合会严重污染跨家族对比实验的独立性。因此，本报告致力于穿透模型命名的表象，直击底层网络架构，在非 Qwen 阵营中遴选出能在单张 40GB A100 显卡上以未经量化的 bf16 精度流畅运行（参数量需控制在约 13B 规模以下），且具备坚实零样本智能体操作基础的通用指令微调视觉语言模型。

## 2025–2026 年开源轻量级 VLM 底层架构与生态演进

在 2025 至 2026 年期间，开源轻量级视觉语言模型（主要集中在 4B 至 13B 参数区间）的生态演进呈现出显著的马太效应与底层架构收敛。随着视觉到文本投影技术（如基于 MLP 的映射器或更为复杂的交叉注意力机制）的标准化，研发团队越来越倾向于将资源投入到高质量多模态预训练语料的清洗上，而将文本推理的基础托付给社区内最成熟的单模态大语言模型。这一趋势导致了大量标榜为全新 VLM 的系统，其内核实际上是 Qwen 体系的延伸。例如，在学术界与工业界均享有盛誉的 MiniCPM-o-2.6 及其前序版本 MiniCPM-V-2.6，虽然在端侧部署与多模态流式交互上实现了突破，但其官方技术文档明确指出，该系列模型是建立在 Qwen2.5-7B 的基础之上构建端到端全模态架构的。这就意味着，如果仅凭模型名称进行筛选，极易将 Qwen 的衍生品误认为独立的架构家族，从而破坏跨家族评测的隔离性原则。

在剔除庞大的 Qwen 衍生生态后，开源社区仍保留了若干坚守独立底层 LLM 架构的稀缺资源。智谱 AI 团队推出的 GLM 系列始终维持着自研的自回归与双向注意力混合架构，其最新开源的 GLM-4V-9B 在 9B 规模下不仅提供了对高分辨率图像的原生支持，还在中文与英文双语环境下的复杂推理中展现了极高的上限。上海人工智能实验室主导的 InternLM 家族则演化出了 InternVL2.5 系列，其中 8B 规模的模型（InternVL2.5-8B）采用了 internlm2_5-7b-chat 作为语言骨干，并在视觉端引入了动态高分辨率切片技术（Dynamic High-Resolution Strategy），允许图像根据原始长宽比被动态划分为多个 448x448 的图块序列，极大地提升了对密集文本页面与 Web 元素的解析精度。

在国际开源阵营中，Mistral 家族通过 Pixtral-12B 实现了具有里程碑意义的架构隔离。该模型不仅采用了 Mistral Nemo 12B 作为文本生成引擎，更值得注意的是，研发团队彻底摒弃了简单拼接现成视觉编码器的捷径，而是从零开始训练了一个 400M 参数量的原生视觉编码器，专门用于无损处理任意长宽比与原始分辨率的图像输入，这为处理复杂且比例极端的长网页滚动截图提供了绝佳的硬件底层保障。与此同时，Microsoft 也在轻量级全模态领域推出了 Phi-4-multimodal-instruct，依托于 3.8B 的 Phi-4-mini 基础模型，通过多重 LoRA（Mixture of LoRAs）机制实现了语言、视觉与语音的统一编码，并在保持极小显存占用的同时，支持长达 128k 的上下文交互。最后，Meta 推出的 Llama-3.2-11B-Vision-Instruct 则直接在经典的 Llama 3 架构上进行了视觉扩展，尽管其在通用视觉问答中表现稳定，但其在结构化动作输出上的潜在局限性构成了复杂的评估变量。

## 零样本原始智能体能力与后训练强化学习的严格剥离

在为受控 Web 智能体研究选择基线模型时，最致命的评测陷阱在于混淆模型的“原始零样本能力”（Raw Zero-Shot Capability）与“后训练智能体能力”（Post-Trained Agentic Capability）。2025–2026 年间，大量文献在 WebArena、VisualWebArena 及 WebVoyager 等基准测试中报告了惊人的成功率（通常高于 20% 甚至突破 40%），但这往往是应用了特定强化学习算法、搜索树策略或直接使用轨迹数据进行监督微调（Agent-SFT）的副产物。在用户的固定脚手架（单一共享提示词结合 JSON 动作空间）下，真正起作用的是模型内部跨模态对齐的鲁棒性以及零样本空间坐标转换能力。任何依赖外部反思机制、多步纠错循环（Test-Time Interaction）或环境奖励微调的分数，都无法反映模型在单纯接受一张截图和一段 HTML DOM 树时，一次性生成精准点击坐标和规范 JSON 的基础素质。

以 Gemma 架构为例，近期学术研究在探讨“推理与执行”（Thinking vs. Doing）的时间扩展机制时，深刻揭示了这种数据通胀现象。研究人员使用 Gemma3-12B 模型在 WebArena-Lite 与 WebVoyager 环境下进行测试，在使用基础的零样本推理时，Gemma3-12B 的原始平均成功率仅为 6.4% 左右。然而，当为其引入动态里程碑（MiRA）策略或测试时交互扩展（TTI）框架，通过在线强化学习让模型在交互过程中不断回溯、重新规划并试错后，其成功率飙升至 43.0% 甚至在某些特定领域突破 66.5%。这种 6.4% 到 43.0% 的巨大鸿沟，完美证明了为何绝不能将排行榜上的峰值作为基线选型的依据。如果仅看 43.0% 的高分，研究者可能会误以为该模型拥有强大的内置 GUI 元素定位与格式约束能力，但实际上，这种成功高度依赖于非零样本设定的额外推理容错空间。

类似的现象也广泛存在于其他开源模型的测试中。例如，在使用 SCALE 框架进行认知边界探索的实验中，原始的 InternVL2.5-8B 在 VisualWebArena 上的零样本表现极具指示意义：在 Shopping 子域仅获得 3.9% 的成功率，Reddit 为 1.4%，Classifieds 为 0.4%，而在具有真实物理 Web 环境动态特性的 WebVoyager 更是直接归零。但在应用了基于 GPT-4o 轨迹模仿学习以及环境探索奖励后，该模型在特定场景下的表现能够获得成倍的提升。此外，专门针对 GUI 操作的特化模型（如 OS-Genesis 或 UI-TARS）在底层逻辑上已经被灌输了大量的屏幕点击、滑动以及系统级菜单调用的成对数据。这些模型虽然在特定测试集上表现优异，但它们已经失去了作为“通用指令微调 VLM”的资格，将其作为对照组投入跨家族通用泛化能力测试，会导致严重的自变量混淆。因此，必须将文献中的 Agent-SFT 成绩彻底从候选名单中剥离，仅关注在极简提示词下一次性前向传播所获得的纯净成功率。

## 候选模型深度技术评估与触底风险分析

在剔除 Qwen 血统与后训练特化模型后，必须对剩余独立家族的通用 VLM 候选者进行极度严苛的技术解剖。这一阶段的评估不仅需要审查其在官方文献或第三方基准中留下的零样本数据锚点，还需要深入探讨其架构设计对固定 JSON 动作空间输出稳定性的潜在影响，并精准核算在未经量化的 bf16 数据类型下，是否能在单张 40GB VRAM 的硬件限制中实现安全部署。

### GLM-4V-9B (Zhipu AI / GLM 家族)

GLM-4V-9B 是一款拥有独立生态与自研语言架构的顶级开源多模态大模型，其语言骨干直接脱胎于 GLM-4 预训练基座。该模型支持 1120x1120 的高分辨率图像输入，并在架构层面进行了针对中英文双语复杂推理的深度对齐。在评估其 Web 智能体原始潜力时，一份引入 WebRL 的研究文献提供了一个极其珍贵的零样本基线锚点：在尚未应用任何强化学习算法干预前，GLM-4-9B 在高度真实的 WebArena-Lite 环境中，取得了 6.1% 的零样本初始成功率。这个 6.1% 的纯净指标恰好与期望目标（≥ ~6%）完美咬合，证明了该模型天生具备较强的空间元素理解能力与结构化文本输出逻辑。从部署资源来看，9B 参数模型在 bf16 精度下的权重体积约为 18GB，在剩余的 22GB 显存内，足以支撑其进行正常的批量推理与视觉 KV 缓存的分配。由于其原生具备 6.1% 的基准表现，其在面对固定脚手架测试时出现类似于 Gemma3-4B-it 那样 1% 触底的风险极低（Low Risk）。

### InternVL2.5-8B (OpenGVLab / InternLM 家族)

InternVL2.5-8B 代表了上海人工智能实验室在视觉语言领域的最高开源结晶，其 LLM 骨干是完全脱离 Qwen 体系的 internlm2_5-7b-chat。该模型在多模态架构设计上坚持了 "ViT-MLP-LLM" 的经典范式，但其视觉感知端采用了一个高度复杂且参数规模达 300M 的增量预训练编码器（InternViT-300M-448px-V2.5）。其独特的动态分辨率策略会根据输入网页截图的实际比例，将其切割为若干个 448x448 的图块进行分批处理，最后在特征层面通过像素反洗（pixel unshuffle）技术进行压缩整合。关于其零样本 Web 导航能力，相关研究直接测得其在 WebArena 的综合平均成功率为 2.3%（在子任务如 OneStopMarket 达到 3.3%），同时在 VisualWebArena 的 Shopping 任务中录得 3.9% 的零样本分数。尽管这些分数略低于理想的 6%，但它们明确证明了模型能够有效解析页面、抓取目标节点并输出符合逻辑的指令序列。8.1B 的参数量在 40GB 显存中部署游刃有余。其触底风险被评估为中等（Medium Risk），主要隐患在于动态图像切片机制在映射回全局相对或绝对点击坐标时，可能因固定的 JSON 空间缺乏特定的偏移量补偿提示而引发定位精度衰减。

### Pixtral-12B-2409 (Mistral AI / Mistral 家族)

Pixtral-12B 代表了欧洲开源社区在多模态理解上的最强音。其语言底座是 Mistral Nemo 12B，这是一个在开源领域备受推崇的高质量指令微调网络。与其他直接借用预训练 CLIP 模型的架构不同，Pixtral 的核心竞争力在于其搭载了一个从零开始训练的 400M 参数量视觉编码器，专门用于在不对输入图像进行任何强制裁剪或压缩变形的前提下，处理自然分辨率与任意长宽比的视觉信号。这一特性对于包含极其细长布局或密集信息块的网页长截图（Web Screenshots）而言，提供了无与伦比的信息保真度。在量化能力评估方面，尽管无法在浩如烟海的文献中剥离出其在 WebArena 上绝对精确的端到端零样本数字，但其在专注于评估智能体底层基础能力的 Agent-RewardBench 测试中，于 Web 感知（Web Perception）维度斩获了 76.5% 的压倒性高分，即使在更复杂的 Web 规划（Web Planning）维度也有 18.9% 的基础响应率。此外，相关评估报告指出其在 Mind2Web 等环境中具备 51.1% 的相对成功率潜力。基于此强大的感知基石，可以合理推断该模型在格式受控的零样本输出中不会出现崩溃式触底，风险处于中等（Medium Risk）。需要警惕的部署瓶颈是，12B 参数在 bf16 精度下基础占用约 24GB VRAM，而该模型支持长达 128k 的上下文窗口；如果在 Web 历史轨迹的回溯过程中盲目堆叠高分辨率长图，极其容易耗尽剩余的 KV-Cache 空间，导致 40GB 显存当场溢出，因此必须实施严格的输入截断。

### Phi-4-multimodal-instruct (Microsoft / Phi 家族)

由微软于 2025 年初发布的 Phi-4-multimodal-instruct 是一个融合了音频、视觉和文本的 5.6B 轻量级全能选手，底座语言网络为 Phi-4-mini。该模型在架构上突破了常规的交叉注意力投影范式，采用了新颖的多重混合 LoRA（Mixture of LoRAs）技术来分别路由不同模态的特征，从而在保持基座语言模型冻结（Frozen）的情况下大幅降低模态间的干扰。针对其在 Web 智能体基准中的表现，文献调研显示其在 Agent-RewardBench 的综合成功率（SR）仅为 0.42（即综合准确率 50.4%）。然而，当面对如 WebInject 这类复杂的对抗性环境注入与指令跟随测试时，Phi-4 模型能够有效地做出响应动作（尽管这也暴露了其面对攻击的脆弱性）。在纯正的 WebArena 或 VisualWebArena 环境中，目前尚未有文献发表该模型未经微调的零样本端到端得分，这种数据盲区构成了核心的不确定性。尽管 5.6B 的参数量在 40GB A100 上部署毫无压力，且推理延迟极低，但由于它并未接受过专门强化长链条 GUI 操作路径的高强度预训练，面对用户严苛的固定 JSON 动作空间，其输出格式的稳定性与防触底安全性无法得到绝对保证，评估风险为中等（Medium Risk）。

### Llama-3.2-11B-Vision-Instruct (Meta / Llama 家族)

Llama-3.2-11B 拥有极为显赫的学术背景，其直接基于 11B 参数级别的 Llama-3.2 文本模型进行了视觉能力扩写。在诸多宏观的多模态测试中，它展现出了作为通用模型的强大实力。然而，在针对 GUI 屏幕交互与 Web 空间解析的垂直探测中，该模型暴露出了令人担忧的结构性缺陷。根据在 hFORMS 评测集与 ScreenQA 零样本设定的交叉验证，Llama-3.2-11B-Vision-Instruct 在页面元素边界框预测（Box Center Prediction, BCP）和重叠度（IoU）上的得分异常低下，例如其零样本 ScreenQA IoU 仅有 0.74，BCP 得分低至 0.92。在更宏观的 WebAgentGuard 与 Agent-RewardBench 智能体评价体系中，其在 Web 感知任务的成绩仅为 50.0%，而在针对特定 Web 动作回调的召回率测试中更是低至 10.08%。更为致命的是，基于同一家族扩展架构的 LLaVA-NeXT-8B 在 VisualWebArena 上录得了完全归零（0%）的基线成绩。综合上述灾难性的空间定位与动作反馈数据，极有理由怀疑 Llama-3.2-11B 模型在面对固定脚手架中严苛的点击坐标映射与深层 JSON 嵌套时，会重演类似于 Gemma3-4B-it 那种因格式错乱或坐标丢失导致的 1% 触底崩盘现象。此模型的触底风险被判定为极高（High Risk）。

## 首选基线模型推荐结论

### 1. GLM-4V-9B

该模型依托完全独立自研的 GLM-4 底层语言架构，完美符合跨模型家族与通用视觉语言模型的苛刻筛选标准，且其 9B 的参数体量能够在单张 40GB 显存显卡上以 bf16 精度极其流畅地运行。该模型在 WebArena-Lite 基准测试中取得了明确的 6.1% 零样本成功率，为其具备原生页面解析与结构化动作输出能力提供了坚实证据，彻底排除了类似 Gemma3-4B 的触底崩溃风险。在本地部署环境与固定脚手架集成时需要特别注意，该家族模型对专有的对话模板（Chat Template）格式极其敏感，若系统提示词的注入未能严格遵循其官方的特殊标记规范，将极易引发底层的灾难性逻辑故障。

### 2. InternVL2.5-8B

本方案采用了彻底脱离 Qwen 体系的 internlm2_5-7b-chat 作为文本核心网络，在提供强大通用指令微调能力的同时，其 8.1B 的适中规模确保了无量化状态下极其稳定的计算与显存占用率。外部的严谨基准测试表明，该模型在 VisualWebArena 的购物子域中实现了 3.9% 的零样本成功率，在包含物理长链条交互的 WebArena 中也获得了 2.3% 的平均成功率，这证实了其在无外部干预下依然具备基础的视觉元素精准定位与动作生成能力。由于该模型在视觉处理管线中强制采用了 448x448 像素的动态切块逻辑，研究人员在注入 JSON 动作空间时必须极其仔细地校准全局坐标的映射逻辑，以防止切片拼接造成的相对或绝对点击位置偏移问题。

### 3. Pixtral-12B-2409

作为基于 Mistral Nemo 12B 语言网络构建的欧洲顶级多模态开源代表，它搭载了原生支持可变长宽比的定制 400M 视觉编码器，使其在处理包含复杂拓扑结构的非标准网页截图时具备了显著的技术前瞻性与跨家族代表性。尽管现有文献网络中缺乏其在 WebArena 上的直接端到端零样本确切分数，但该模型在 Agent-RewardBench 的 Web 感知维度的压力测试中斩获了高达 76.5% 的优异成绩，充分证明了其卓越的底层视觉语素对齐能力，大大压低了在固定提示词测试中的触底概率。部署实施时面临的最严峻挑战在于，其高达 12B 的网络参数量将在 bf16 精度下固定占用约 24GB 的静态显存；在面对最高可达 128k 令牌的上下文窗口时，系统必须对输入网页截图的历史记录进行无情的标记流截断管理，以避免单张 A100-40GB 显存发生致命溢出。

## 明确排除模型名录与架构审查

在深挖 2025–2026 年间的技术白皮书与开源架构树时，许多在排行榜上名列前茅的模型由于触犯了硬性评测指标（Hard Criteria）的红线，被毫无妥协地从候选名单中予以剔除：

- **MiniCPM-V-2.6 / MiniCPM-o-2.6**：这一系列模型在各类公开多模态榜单及移动设备部署优化上表现惊艳，其极低的令牌开销使其深受开发社区青睐。然而，开发团队的技术报告明确揭示，为了获取更为强大的多语言泛化与逻辑推演能力，2.6 版本的底层大语言模型骨干已被全面切换为 `Qwen2.5-7B`。鉴于当前受控实验中的 B0 和 B1 均已被 Qwen 家族深度绑定，引入 MiniCPM 将导致同系架构的严重过度代表，因此基于“非 Qwen 骨干”的第一硬性准则将其无情一票否决。
- **Gemma-3-12B-it**：该模型在最新的测试网络中展现出了统治级别的潜力，特别是其在 WebArena-Lite 上的零样本基线成功率已达到了极其优异的 6.4%，并且在后续引入 MiRA 动态里程碑规划算法后，成功率甚至攀升至 43.0% 的惊人水平。然而，当前实验基线中的 B2 已经固定为 `Gemma3-4B-it`。引入一个同门但参数更大的 12B 版本，虽然绝对可以解决 B2 在 1% 处挣扎的触底问题，但这种操作属于典型的同家族向上扩展（intra-family scale-up）。它无法为本项研究提供来自第三个独立底层架构体系的真实交叉对比信号，从而失去了作为独立控制变量的学术意义。
- **UI-TARS (7B) / OS-Genesis / AutoGLM-OS**：这些系统在 WebVoyager 或 Mind2Web 的各种自动评估榜单中频繁占据高达 20% 甚至更高的统治性分数。但需要深刻认识到，它们无一例外均属于高度定制化的 GUI 专家智能体模型（GUI-specialist agent models）。在它们的训练管线中，被灌注了海量关于操作系统底层 API、鼠标精准滑动、复杂界面点击模拟的轨迹行为克隆数据，甚至应用了持续的在线强化学习（如 WebRL）。将这种高度特化的环境操控工具与 Qwen3-VL 或 Gemma3 等仅经过通用视觉指令微调的基础大模型置于同一评测平面，会引发不可调和的实验偏差，公然违反了寻找“通用指令微调 VLM”的强制规定。
- **Ovis2.6-30B-A3B**：这款前沿模型采用了极具经济学效率的混合专家（MoE）底层网络，并且原生强化了对超长文本与 2880x2880 极高分辨率截图的无缝解析能力，针对密集业务文档的评测极具看点。然而，其网络总参数量已经激增至 30B 级别。尽管在推理激活期间只有约 3B 维度的参数参与运算从而降低了浮点负担，但在模型加载进入显存（未量化 bf16 精度）的初始阶段，将强行索取超过 60GB 的物理显存空间。这一硬件门槛直接击穿了单张 40GB A100 VRAM 的安全防线。

## 评测盲区与零样本数据的客观不确定性

在秉持最高学术透明度的原则下，必须坦诚地指出在本次跨家族基线筛选过程中所遭遇的文献数据盲区（Blind Spots）与难以完全消解的客观风险。最核心的不确定性在于，业界对于模型真实能力的基准测试已经极度向强化学习与后训练技术偏移，导致难以捕获纯净的原始数据。

首先，针对 **Pixtral-12B-2409** 和 **Phi-4-multimodal-instruct** 这两大拥有极高架构独立价值的候选者，穷尽了 2025–2026 年可用的文献库与排行榜，依然无法找到它们在 WebArena 或 VisualWebArena 上的权威官方、未经 SFT 处理且无交互干预的直接端到端零样本成功率具体数值。虽然 Pixtral-12B 在 Agent-RewardBench 中的 Web 感知分项以 76.5% 的压倒性优势领跑，并在某综合测评中达到了 51.1% 的 Mind2Web 相对成功率指标；Phi-4 也在底层特征处理和复杂 Web 注入识别（WebInject）中展现出非凡的反馈特征。但在您设计的“共享提示词加上固定 JSON 动作空间”这种容错率极低的测试框架内，即使模型感知到了正确的 GUI 节点，只要在输出多层嵌套的 JSON 语法或绝对屏幕坐标映射时出现轻微幻觉，就会导致智能体操作链条瞬间崩断。这种因缺乏零样本物理数据支撑而产生的未知触底概率，构成了不可忽视的隐藏风险。

其次，对于特定底层架构在处理高度结构化二维界面时的先天性缺陷，目前仍缺乏系统性的病理学解释。例如，在传统文本推理任务中表现绝佳的 **Llama-3.2-11B-Vision-Instruct** 架构，其在应对基于 GUI 的位置反馈任务时表现出了令人费解的失能。其边界框中心点预测准确率甚至不及某些 3B 规模的模型，而且这种视觉空间感知的劣势直接传导至整个系统的指令回调之中，致使其在各类 Web 防护与动作评估基准中的分数断崖式暴跌。这种基于特定架构的网络先天限制进一步印证了您的担忧：如果不经过海量专门针对屏幕截图与鼠标坐标对齐的监督数据微调，贸然将缺乏空间结构特化的大型预训练模型直接塞入 Web 智能体的零样本评测框架，其遭遇 1% 甚至 0% 成功率滑铁卢的几率是极其现实存在的。这再次凸显了将 `GLM-4V-9B`（具备确定性的 6.1% 零样本成功率）作为第四基线 B3 选项的最优可行性与绝对安全性。
