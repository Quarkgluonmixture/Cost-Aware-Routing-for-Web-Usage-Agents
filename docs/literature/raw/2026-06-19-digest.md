## Score 3 (paper 引用候选)

### [Adaptive Vision-Language Model Routing for Computer Use Agents (AVR)](https://arxiv.org/abs/2603.12823)
- **TL;DR**: 给 CUA 每步动作按难度路由到最便宜的达标 VLM
- **关联 narrative**: cascade routing + 4-fold cost dimension —— 几乎是 P79 的直接 sibling：computer-use agent 的 cost-aware VLM 路由
- **关联 paper §**: §1 (cost-aware routing) / §6 (cascade)
- **关联 paper_planning anchor**: cost-accuracy threshold policy；warm-agent 检索缩小 capability gap；高危动作升级
- **方法/结果**: 在 orchestrator 与 VLM 池之间插入轻量语义路由层；用多模态 embedding 估动作难度 + 小 VLM 探置信度，路由到"满足可靠性阈值的最便宜模型"；warm agent 用历史交互检索缩小大小模型差距；高危动作直接升级强模型。ScreenSpot-Pro + OpenClaw agent routing benchmark，成本降 78% 且精度在 all-large baseline 的 2pp 内。代码 vllm-project/semantic-router。
- **Authors**: Xunzhuo Liu, Bowei He, Xue Liu, Andy Luo, Haichen Zhang, Huamin Chen
- **Date**: 2026-03-13 (arXiv) | **arXiv ID**: 2603.12823
- **备注**: 时间偏早但与本课题重叠度最高，建议确认 related work 是否已引；其 warm-agent 检索与高危升级机制可与 P79 路由设计直接对比。

### [How do LLMs Compute Verbal Confidence?](https://arxiv.org/abs/2603.17839)
- **TL;DR**: verbal confidence 是答案位缓存、再检索，非事后拼凑
- **关联 narrative**: mid-layer mechanism + cascade routing —— 解释 verbal confidence 作为路由/弃答信号的机制基础
- **关联 paper §**: §5 (mechanism) —— verbal AUROC / behavioral AUROC 的可解释性
- **关联 paper_planning anchor**: hidden state probe；decoding stage failure；activation patching 定位信息流
- **方法/结果**: Gemma3-27B / Qwen2.5-7B / Magistral-24B。用 activation patching / steering / noising / swap + attention blocking 做因果定位，发现信息流为：置信度信息从 answer token 收集 → 缓存在第一个 answer 后位置 → 在 verbalization 位检索输出。linear probing + variance partitioning 表明该缓存表示超出 token logprob，是更丰富的答案质量评估。结论：verbal confidence 是自动的自评而非事后重建。
- **Authors**: Dharshan Kumaran, Arthur Conmy, Federico Barbero, Simon Osindero, Viorica Patraucean, Petar Veličković
- **Date**: 2026-03-18, v3 2026-05-19 | **arXiv ID**: 2603.17839
- **备注**: v3 上月更新。若 P79 用 verbal confidence 做路由/abstain，这篇给的是它"为何可靠/不可靠"的因果定位，可与 P79 的 verbal AUROC 现象互证。

## Score 2 (related work / baseline / failure-mode contrast)

- **[Toward Calibrated Mixture-of-Experts Under Distribution Shift](https://arxiv.org/abs/2606.20544)** (Wong, Prinster, Saria, Chellappa, Liu; ICML 2026; 2606.20544) — hard-routed MoE 下 expert 级 calibration 即可保证整体在 distribution shift 下校准，soft-routed 则不够；提出对抗再加权惩罚 routed aggregate 的校准误差。命中 L0 expert routing + L1 calibration。为 P79 的路由稳健性/校准提供跨模型类比的条件分析。
- **[A Systematic Evaluation of Black-Box Uncertainty Estimation Methods for LLMs](https://arxiv.org/abs/2606.19868)** (Wang, Zhang; 2606.19868) — 把黑盒不确定度估计分成 verbalization / sampling / explanation / multi-agent / hybrid 五类，横评 24 种方法，结论"无单一赢家、hybrid 最稳"。命中 L1 calibration + verbal confidence。直接关系到 P79 在 API-only 模型上选哪个置信度信号做路由。
- **[GEMS: Geometric Constraints Enable Multi-Semantic Superposition in LLMs](https://arxiv.org/abs/2606.19946)** (Deng; 2606.19946) — training-free，用几何约束把多个语义源映射为可叠加的 steering 方向，实现多语义叠加控制。命中 L0 steering vector / superposition。机制 narrative 的可迁移 steering 方法。
- **[HANSEL: Extracting Breadcrumbs from Web Agent Trajectories for Interactive Verification](https://arxiv.org/abs/2606.18671)** (Zhang, Nam; 2606.18671) — 从 web agent 轨迹里抽可交互、可验证的 evidence link（Highlighting Agent Navigation Steps as Evidence Links）。命中 L2 browser/web agent。对 P79 的 web agent 评估与失败定位有参考。

## Score 1 (awareness)

- **[LedgerAgent: Structured State for Policy-Adherent Tool-Calling Agents](https://arxiv.org/abs/2606.20529)** (2606.20529) — 给 tool-calling agent 维护独立结构化 ledger 状态，在执行环境变更工具前主动阻断状态相关策略违规；pass^k 在多轮一致性指标上提升最明显。
- **[Automating SKILL.md Generation for Computer-Using Agents](https://arxiv.org/abs/2606.20363)** (2606.20363) — 诊断性研究：从 GUI 交互轨迹挖 skill 库，可读性高（8 簇中 5 簇 purity≥0.95）但跨域策略迁移失败（GRPO 18.5%→20.5%，BrowseComp+ 基本不变）。一个"skill 库可读≠策略更好"的反例，可供 P79 讨论 scaffold/skill 时引用。
- **[google-gemini/gemini-cli](https://github.com/google-gemini/gemini-cli)** — Google 开源终端 agent，同时是 MCP client + MCP server，105k+ stars 持续活跃；MCP 生态参考。
