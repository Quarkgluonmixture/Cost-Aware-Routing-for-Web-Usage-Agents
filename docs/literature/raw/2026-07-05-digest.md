## Score 3 (paper-引用候选)

### How Vision Becomes Language: A Layer-wise Information-Theoretic Analysis of Multimodal Reasoning
- **TL;DR** (50 chars): 视觉信息早层达峰后衰减，语言信息晚期占 82%
- **RELATION**: SUPPORT — 用逐层信息论分解直接佐证 P79 §5 mechanism 的核心 claim
- **命中 LIVE claim / §**: §5 mechanism（兼 §3 definition）。论文用 Partial Information Decomposition（偏信息分解，把每层预测信息拆成冗余/视觉独有/语言独有/协同四份的信息论方法）逐层解剖 LLaVA-1.5/1.6-7B 在六个 GQA 任务上的预测信息，发现一致的 "modal transduction" 模式：visual-unique 信息在早期层达峰、随深度单调衰减；language-unique 信息在晚期层激增、最终占预测信息约 82%；cross-modal synergy 全程低于 2%。这直接对应 P79 的 "language prior dominance" / "decoding stage failure" / "middle layer cross-modal" / "seeing but not believing" claim。因果性通过 Image→Question attention knockout 验证：打断主通路会可预测地抬升被困的 visual-unique 信息、补偿性 synergy 与总信息代价，在视觉依赖任务上最强。layer-wise 轨迹跨模型变体相关性 >0.96，高度稳定。
- **关联 paper_planning anchor**: Cross-modal flow / mid-layer attention decay / language prior dominance
- **Authors**: Hongxuan Wu, Yukun Zhang, Xueqing Zhou
- **Date**: 2026-02-17 (arXiv v1)
- **arXiv ID**: 2602.15580
- **外推风险**: 实验在 VQA（LLaVA + GQA）上做，非 web agent + representation routing。但其逐层信息流模式（视觉早峰后衰 → 语言晚期主导 → 融合几乎为零）正是 P79 §5 想刻画的机制结构，作为 mechanism 叙事的佐证成立；不能当 web-agent 场景的直接实验证据。

### Linear Probes Detect Task Format, Not Reasoning Mode in Language Model Hidden States
- **TL;DR** (50 chars): 100% probe 准确率全是格式混淆，去混淆后降为随机
- **RELATION**: THREAT — 直接攻击 P79 §5 的线性探针方法学，进 reviewer-预案
- **命中 LIVE claim / §**: §5 mechanism（方法学）。论文在 Qwen3-14B 第 32/40 层对三种推理类型（演绎/归纳/溯因）做线性探针，表面 cross-validated 准确率 100%、几何分离漂亮（intrinsic dim 20.6-33.6，convex hull contamination ≤1.5%）。但 residualize 掉 source identity / option count / response length 三个格式变量后准确率跌回 chance（33.3%）；n=20 的 causal steering 随机对照下几何与推理模式无功能关联（p=0.286）。结论：高 probe 准确率反映的是 task format 而非计算结构，mech-interp 必须常规做 format deconfounding。
- **关联 paper_planning anchor**: hidden state probe / linear probe / PCA cosine gap
- **Authors**: Subramanyam Sahoo, Vinija Jain, Aman Chadha, Divya Chaudhary
- **Date**: 2026-06-01 (v1) / 2026-06-03 (v2)，TrustNLP @ ACL 2026
- **arXiv ID**: 2606.02907
- **reviewer-预案要点**: hostile reviewer 会拿这篇打 P79 的探针证据——"你的 linear probe / PCA cosine gap 只是在读 format，不是真正的 routing 表征"。应对：(1) P79 必须对 option count / prompt 长度 / observation 表面模态特征做 residualize，证明分离不来自这些 confound；(2) 不能只报 observational probe accuracy，要补 causal steering——证明干预 routing 方向真的翻转模型决策（这篇正好提供了 p 值对照范式）；(3) P79 的 phantom 轴本就是 format × decision-style，所以 "format confound" 部分就是现象本身——这点必须正面说清楚，否则被当成缺陷。这篇与 §5 用探针论证 routing 可线性解码的所有 claim 直接冲突，必须正面回应。

### Late-Layer Fusion is Enough: Dual-Path Vision Token Routing for MLLMs under Visual Saturation (DPVR)
- **arXiv**: [2606.09131](https://arxiv.org/abs/2606.09131) | 2026-06-08 | Siyuan Liu, Jinyang Wu et al. | Pattern Recognition 投稿
- **RELATION**: SUPPORT (distant) / DESIGN-INPUT — §5 mechanism + §6 router。逐层分析 LLaVA-1.5 发现 text-to-image attention 从 layer 0 的 0.68 崩到 layer 4 的 0.07、layer 18 后稳定在 ~0.04——视觉 token 在中间层饱和。经验性地记录了 P79 §5 想说的 "mid-layer attention decay"。但论文贡献是效率架构（DPVR-LF，单层晚期融合即可保住感知能力），不是机制 claim 本身，且轴是 VLM 推理效率不是 phantom format。
- **外推风险**: VLM efficiency domain，非 web agent。
- **命中 keyword**: mid-layer attention decay, middle layer cross-modal

### Probing for Knowledge Attribution in Large Language Models
- **arXiv**: [2602.22787](https://arxiv.org/abs/2602.22787) | 2026-02
- **RELATION**: RELATED-ONLY — §5 方法学。用自监督 AttriWiki 训练的线性探针能可靠预测答案是来自 context 还是 model weights（Llama-3.1-8B / Mistral-7B / Qwen-7B 上 0.96 Macro-F1，OOD 到 SQuAD/WebQuestions 0.94-0.99 不重训）。方法学上佐证 hidden state 上做线性探针的可行性，但 domain 是知识归因不是 routing。注意：这篇 "探针可信" 的立场与上面 2606.02907 "探针读的是 format" 形成张力，P79 引用时需并置讨论。
- **命中 keyword**: hidden state probe, linear probe

### Steering MoE LLMs via Expert (De)Activation (SteerMoE)
- **arXiv**: [2509.09660](https://arxiv.org/abs/2509.09660) | 2025-09 | adobe-research（[GitHub](https://github.com/adobe-research/SteerMoE)）
- **RELATION**: RELATED-ONLY (L0 白名单点名 anchor) — §5 / §6。检测 MoE 中与行为挂钩的 expert，通过 (de)activation 做 test-time steering，11 benchmark / 6 模型上 safety +20%、faithfulness +27%，并揭示 MoE routing 的脆弱性。概念上支持 "routing 决策局部化、可识别、可干预" 的叙事，但轴是 MoE FFN expert routing，不是 observation-format routing。
- **外推风险**: MoE expert axis ≠ phantom format axis。
- **命中 keyword**: SteerMoE, expert routing, steering vector
