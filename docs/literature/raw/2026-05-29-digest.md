### [Same Task, Different Circuits: Disentangling Modality-Specific Mechanisms in VLMs](https://arxiv.org/abs/2506.09047)
- **TL;DR** (50 chars): VLM 中 visual vs text circuit 结构分离
- **RELATION**: SUPPORT — 直接佐证 §5 的 mid-layer cross-modal flow bottleneck
- **命中 LIVE claim / §**: §5 mechanism — 用 activation patching 发现 VLM 中 visual vs text 的 circuit 大部分结构不重叠（平均仅 18% 组件共享），但功能相似。关键发现：image data representation 只在后层才与 text representation 对齐——太晚以至于无法有效影响后续位置。将后层 representation patch 回前层可关闭 1/3 的 modality gap。
- **关联 paper_planning anchor**: Cross-modal flow / mid-layer attention decay
- **Authors**: Yaniv Nikankin, Dana Arad, Yossi Gandelsman, Yonatan Belinkov (Technion / UC Berkeley)
- **Date**: 2025-06-10 (revised 2025-10-03)
- **arXiv ID**: 2506.09047
- **Venue**: NeurIPS 2025
- **P79 对接**: "image rep 对齐太晚"直接支持 P79 phantom 的核心 claim：visual input 在中间层还没被正确 routing，phantom（text-only / SoM / AXTree）之所以能 work，恰恰因为 text path 的 circuit 更早完成对齐。training-free 的 late-to-early patching 也给 P79 的 intervention 设计提供了参照。**外推风险**: 他们在 counting / board-game 等简单任务上验证，P79 是 web agent grounding，复杂度不同。
