### [TIGER: Traceable Inference with Graph-Based Evidence Routing for Mitigating Hallucinations in Multimodal Generation](https://arxiv.org/abs/2606.00232)
- **TL;DR** (50 chars): Graph-based evidence routing 做 fact-level hallucination repair
- **RELATION**: DESIGN-INPUT — observation graph + claim graph 的分离提取架构为 P79 phantom format 的 observation representation 提供直接参考
- **命中 LIVE claim / §**: §3 definition (observation format 的结构化表示), §5 mechanism (graph-conditioned risk score 类似 phantom confidence signal)
- **关联 paper_planning anchor**: from: Mirage / Confidence Routing
- **Authors**: Kaixiang Zhao, Tianrun Yu, Shawn Huang, Porter Jenkins, Yushun Dong, Amanda Hughes
- **Date**: 2026-05-29, **arXiv ID**: 2606.00232
- **关键发现**: TIGER 独立地从输入中提取 observation graph，从输出中提取 claim graph，然后基于 support/conflict 关系为每个 claim 分配 graph-conditioned risk score。核心创新是输入和输出的表示完全解耦——输出中的 hallucinated claim 不会反向污染对输入的解读。提供了收敛分析证明总风险在温和假设下几何递减到显式渐近界。在 image-to-text、image+text-to-text、audio-to-text、video-to-text 四条跨模态路径上验证，CrisisFACTS case study 显示同一 repair 机制在多源场景也能改善 grounding。
- **P79 对接**: TIGER 的 observation graph 提取方法可以直接移植到 P79 的 phantom arm 设计中。当前 P79 的 AXTree arm 本质上是一种 flat observation representation；如果改用 graph 结构来表示 DOM（节点 = UI elements, 边 = spatial/hierarchical relations），TIGER 的 graph-conditioned risk score 框架可以为每个 observation element 计算一个 grounding confidence。这意味着 P79 的 phantom router 不再需要依赖 verbal confidence 或 log-prob，而是可以直接从 observation structure 中读出 confidence——一种更 principled 的 routing signal。
- **Domain mismatch / 外推风险**: TIGER 验证的主要是 image/audio/video → text 生成场景，不是 web agent action prediction。但从输入中提取 structured observation graph 然后 scoring 的范式与 P79 的 DOM → observation → action pipeline 结构对齐。收敛保证依赖 claim graph 的 independence 假设，在 DOM 场景中 UI elements 之间有强相关性，这需要额外验证。

### [The Deterministic Horizon: When Extended Reasoning Fails and Tool Delegation Becomes Necessary](https://arxiv.org/abs/2606.00376)
- **TL;DR** (50 chars): 纯推理在 deterministic state-tracking 31 步后崩溃，必须 delegate
- **RELATION**: SUPPORT + DESIGN-INPUT — 直接为 P79 §6 router 提供 "何时 route" 的理论界限
- **命中 LIVE claim / §**: §6 router (routing decision 的理论依据), §4 empirical (WebArena 上 text-only vs tool-augmented 的性能差距)
- **关联 paper_planning anchor**: from: Cost-Aware Router / RouteLLM
- **Authors**: Dongxin Guo, Jikun Wu, Siu Ming Yiu
- **Date**: 2026-05-29, **arXiv ID**: 2606.00376 | **Venue**: ICML 2026
- **关键发现**: 提出 Attention Bottleneck Theorem 并给出互补的 achievability construction，将 decoder-only model 的 state-tracking capacity 上界定为 O(H · log(L/H) · √d_h)。导出 context-dependent error model，accuracy 衰减是 super-exponential 的。引入 State-Space Jaccard metric 区分 capability failure 和 preference failure。在 12 个模型、8 个任务域（包括 SWE-Bench, WebArena, SQL-Multi）上实验：tool-integrated reasoning 准确率 86-94%，纯 neural CoT 仅 24-42%。fine-tuning 改善 < 5%，确认这是 architectural ceiling。跨模型相关 r = 0.81-0.91。
- **P79 对接**: P79 的 phantom format 实验本质上是在测试不同 observation format 下 LLM 的 state-tracking capability。The Deterministic Horizon d* ∈ [19, 31] 意味着当 web task 的 DOM state变化超过这个阈值，纯 text-only arm（即不带外部工具的 phantom observation）的 performance 必然崩塌。这为 P79 §6 router 提供了一个理论 grounding：不要靠 empirical calibration 来决定何时 route，而是直接用 task horizon length 作为 routing feature。而且跨模型 r = 0.81-0.91 说明这个界限是 architecture-level 的，不需要 per-model calibration。
- **Domain mismatch / 外推风险**: 论文的理论分析基于 linear attention model 的简化假设，实际 transformer 中的 multi-head attention + MLP 可能放宽这个界限。WebArena 实验数据直接可用。State-Space Jaccard metric 在 P79 的 phantom format 条件下需要适配（因为 P79 比较的是 observation format 而非 tool augmentation）。

## Score 2 (related work)

### [MIRAGE: Mobile Agents with Implicit Reasoning and Generative World Models](https://arxiv.org/abs/2606.04627)
- **TL;DR**: Latent reasoning 替代 explicit CoT，3-5x token reduction，world-model objective 预测未来 UI 状态
- **RELATION**: DESIGN-INPUT — latent reasoning + world-model objective 为 P79 phantom arm 的 internal representation 提供参考
- **关键词命中**: mobile agent, latent reasoning, world model, token reduction (L1)
- **Authors**: Zhichao Yang, Yuanze Hu, Haojie Hao, Longkun Hao, Dongshuo Huang, Hongyu Lin, Gen Li, Lanqing Hong, Yihang Lou, Yan Bai | **Date**: 2026-06-03 | **arXiv ID**: 2606.04627
- **P79 对接**: MIRAGE 的核心发现（explicit CoT 可以被压缩到 latent space 而不丢 performance）对 P79 有两面影响。一方面，如果 phantom format 的 text-only arm 实际上在做一种 implicit latent reasoning（利用 language prior 而非真正 reading the screen），MIRAGE 提供了这种机制的独立验证。另一方面，MIRAGE 的 world-model objective（latent reasoning vectors aligned with future screenshots）暗示一种新的 phantom arm 设计：让 P79 的 router 不仅看当前 observation format 的 confidence，还看 model 是否成功预测了下一步 observation——如果 text-only arm 的 latent state 已经 encode 了下一步的 DOM structure，说明这个 task 不需要 visual observation。

### [Capability Self-Assessment: Teaching LLMs to Know Their Limits](https://arxiv.org/abs/2606.00251)
- **TL;DR**: RL 教 LLM 学会 Self-SOLVE vs DELEGATE 的 binary decision，SFT 不行
- **RELATION**: DESIGN-INPUT — CSA 的 policy-learning formulation 直接为 P79 §6 router 提供训练范式
- **关键词命中**: capability assessment, delegation, routing, RL (L1)
- **Authors**: Yang et al. | **Date**: 2026-06-01 | **arXiv ID**: 2606.00251
- **P79 对接**: CSA 将 "要不要自己处理" 建模为 policy-learning problem，发现 RL 显著优于 SFT 且不损害原始能力。这个 finding 对 P79 §6 的 LR router 有直接参考价值：如果 P79 的 router 不是用 log-prob 或 verbal confidence 做 routing，而是直接训练一个 Self-SOLVE vs DELEGATE 的 policy（phantom arm = Self-SOLVE, full-observation arm = DELEGATE），可能比 hand-crafted confidence features 更鲁棒。

### [Latent Reward Steering: An Adaptive Inference-Time Framework for Reasoning LLMs](https://arxiv.org/abs/2606.00726)
- **TL;DR**: SAE latent state 上的 reward model 做 inference-time steering，自动修复脆弱推理
- **RELATION**: RELATED-ONLY — SAE latent reward 为 P79 §5 mechanism 的 activation analysis 提供新工具
- **关键词命中**: SAE, latent steering, reward model, inference-time (L0)
- **Authors**: Li et al. | **Date**: 2026-06-02 | **arXiv ID**: 2606.00726
- **P79 对接**: LRS 用 SAE latent state 上的 learned reward model 做 state-specific correction，配合 reward + confidence gate 限制干预范围。如果 P79 §5 的 activation patching 发现 phantom format 条件下某些 SAE features 有系统性差异，LRS 的 reward gradient 可以用来做 intervention direction，比 random ablation 更有 principled guidance。
