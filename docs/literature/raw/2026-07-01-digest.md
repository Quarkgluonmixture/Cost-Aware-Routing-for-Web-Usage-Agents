## Score 3 (paper-引用候选)

### 1. Tool Calling is Linearly Readable and Steerable in Language Models
- **arXiv**: [2605.07990](https://arxiv.org/abs/2605.07990)
- **TL;DR** (≤50字): 工具选择=单一可读可操线性方向；activation patching 定位中后层 head；top-1/top-2 gap 预测误调达 21x
- **RELATION**: SUPPORT（同时兼 DESIGN-INPUT）— 直接命中多条 LIVE 机制/router claim，且作者来自 UCL（Perez-Ortiz 组），与本课题同机构。
- **命中 LIVE claim / §**:
  - **§5 mechanism**: activation patching 把工具选择局部化到一组**中-后段 attention heads**，与 phantom 的 mid-layer 路由定位一致。
  - **"knows but cannot say" / decoding-stage-failure**: base model 用 cosine readout 可读出 61–82% 的正确工具，但直接生成只有 2–10% → 表征在预训练已形成、instruction tuning 才接到输出。直接佐证「内部已表征、解码阶段失败」。
  - **§6 router / PCA cosine gap**: top-1 与 top-2 工具的表征 gap 最小的 query，误调率高 **21x**（Gemma-3 27B）。gap 即天然的 confidence / 升级信号，可直接喂 router。
- **关联 paper_planning anchor**: Tool Calling Linear Circuit（主）、PCA cosine gap、decoding stage failure
- **Authors**: Zekun Wu, Ze Wang, Seonglae Cho, Yufei Yang, Adriano Koshiyama, Sahan Bulathwela, Maria Perez-Ortiz
- **Affil**: UCL, Holistic AI, Imperial College London
- **Date**: 2026-05-08（v2 2026-05-25），ACL ARR May 2026
- **诚实约束 / 外推风险**: 实验设定是 **single-turn fixed-menu tool selection**（选哪个工具），并非 web-agent 的 format×decision-style 轴。因此它**直接验证**的是「工具/决策选择的线性可读 + 中后层定位 + gap 预测错误」这一机制与 router-confidence claim，**不**直接验证 phantom 三臂（P-text/P-prompt/P-SoM）的 format 差异。引用时定位为「机制与 router 的跨域类比证据」，而非 phantom format 轴的直接证据。

### 2. Linear Probes Detect Task Format, Not Reasoning Mode in Language Model Hidden States
- **arXiv**: [2606.02907](https://arxiv.org/abs/2606.02907)
- **TL;DR** (≤50字): probe 对推理类型的 100% 分离完全由格式混淆驱动；residualize 后降至随机，因果 steering 无效（p=0.286）
- **RELATION**: **THREAT** — 可被 hostile reviewer 拿来攻击本课题任何「probe/几何分离 ⇒ 存在 phantom 差异表征」式的机制 claim。进 reviewer 预案，**不进 bib 正文**（或仅进 §4-limitations-disclosure）。
- **命中 LIVE claim / §**: **§5 mechanism** 与 **§4-limitations-disclosure**。本 paper 用 **Qwen3-14B**（与本课题同模型族），layer 32/40；控制 source identity / option count / response length 后 probe 精度从 100% 崩到随机；20 次随机向量对照的因果 steering 无显著效应。
- **reviewer-预案要点**（务必落实）:
  1. phantom 轴本就是 **format × decision-style** —— 这篇恰好在说「probe 检测的是 format 而非计算结构」。reviewer 会主张：你们的 probe 分离只是在测 format（即你们自己定义的轴），是**同义反复 / 表面 artifact**，不构成「存在 distinct 计算/表征」的证据。
  2. **必须做的 deconfound**：在机制实验里 residualize 掉 option count、response length、source/template identity；并跑该 paper 的 **random-vector 因果对照**（其 p=0.286 协议），证明几何分离不是单纯 format artifact。
  3. 论证口径改为：「分离 ≠ distinct computation；我们用因果 patching/steering 而非单纯 probe 精度来立论」，避免被这篇逐条反驳。
- **关联 paper_planning anchor**: linear probe / hidden state probe、PCA cosine gap
- **Authors**: Subramanyam Sahoo, Vinija Jain, Aman Chadha, Divya Chaudhary
- **Date**: 2026-06-01（v2 2026-06-03），accepted 6th Workshop on Trustworthy NLP, ACL 2026
- **Domain 备注**: 纯推理 benchmark（LogiQA/ARC/αNLI），非 web agent；但威胁点（probe-format 混淆）跨域成立，是本课题机制章最需要预案的一篇。

### Dynamic Multimodal Activation Steering for Hallucination Mitigation in Large Vision-Language Models
- [ICLR 2026, OpenReview YtWZdwEG5K](https://openreview.net/forum?id=YtWZdwEG5K)
- **TL;DR**: LVLM 中 truthfulness 与 visual perception 主要占用**不同的 attention head 子集**，且 truthfulness steering vector 随语义上下文显著变化 → 训练-free、按上下文动态选 head 干预。

### UCCI: Calibrated Uncertainty for Cost-Optimal LLM Cascade Routing
- [arXiv 2605.18796](https://arxiv.org/abs/2605.18796) · code: github.com/varunkotte6/ucci
- **TL;DR**: calibration-first cascade router，把 token-level margin uncertainty 经 isotonic regression 映射成 per-query error probability，按受限 cost 最小化选升级阈值。
- **RELATION**: DESIGN-INPUT（§6 router）— 「margin uncertainty → 校准 error prob → 成本最优阈值」可直接借鉴 P79 router 的 confidence→升级决策；理论给出 O(n^-1/3) ECE。
- **外推风险**: domain 是 NER / 纯 LLM cascade（4B+12B），非 web agent。confidence 校准思路可迁移，但绝对数值不可照搬。

### ParetoBandit: Budget-Paced Adaptive Routing for Non-Stationary LLM Serving
- [arXiv 2604.00136](https://arxiv.org/abs/2604.00136) · code: github.com/ParetoBandit/ParetoBandit
- **TL;DR**: cost-aware contextual-bandit router，在线 primal-dual 预算 pacing 强制 $ 预算上限，几何遗忘适应价格/质量漂移，支持运行时热插拔模型。
- **RELATION**: DESIGN-INPUT（§6 router）— 预算约束下的自适应路由 + 非平稳 serving，对 cost-aware 路由的预算-质量权衡有方法借鉴。
- **外推风险**: general benchmark prompts / 纯 LLM serving，非 web agent；预算 pacing 概念可迁移，实验设定不可直接比。
