## Score 3 (paper-引用候选)

### Tool Calling is Linearly Readable and Steerable in Language Models
- **TL;DR** (50 chars): 工具选择是激活空间里的单一线性方向，可读可写
- **RELATION**: SUPPORT — 直接佐证 P79 §5 mechanism 的核心论点：routing 决策在 hidden state 里是线性可解码的
- **命中 LIVE claim / §**: §5 mechanism。论文发现：(1) 工具身份由单一方向编码，加该方向即可翻转模型选哪个工具；(2) base model 在还不能输出工具名时，cosine readout 已恢复 61-82% 准确率（generation 仅 2-10%），说明预训练已形成表征、instruction tuning 只是接线到输出——这直接呼应 P79 的 "language prior dominance" / "decoding stage failure" claim；(3) top-1 与 top-2 工具 cosine gap 最小的 query 错误率高 21×，与 P79 的 PCA cosine gap → error 预测高度一致
- **关联 paper_planning anchor**: Tool Calling Linear Circuit / hidden state probe / linear steerable
- **Authors**: Zekun Wu, Ze Wang, Seonglae Cho, Yufei Yang, Adriano Koshiyama, Sahan Bulathwela, Maria Perez-Ortiz (UCL, Holistic AI, Imperial College London)
- **Date**: v2 2026-05-25 (ACL ARR May 2026 / EMNLP 2026)
- **arXiv ID**: 2605.07990
- **外推风险**: 纯文本 tool calling（single-turn, fixed-menu），非 web agent + representation routing。多轮 agent loop 下同一干预不稳定（gain/loss ±30pp 无一致方向）。P79 的 phantom 轴是 format × decision-style，本文的 "linear readability" 是在 text tool-calling 上证的——作为 mechanism 叙事的佐证成立，但不能当直接实验证据
