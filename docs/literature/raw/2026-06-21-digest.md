## Score 3 (paper 引用候选)

### [Visuals Lie, Consistency Speaks: Disentangling Spatial Attention from Reliability in Vision-Language Models](https://arxiv.org/abs/2606.17389)
- **TL;DR**: VLM 可靠性与视觉注意力几乎无关，由生成动力学决定
- **关联 narrative**: phantom space / mid-layer mechanism / cross-capability robustness —— 直接挑战"注意力集中=可信"的直觉
- **关联 paper §**: §5 (mechanism) —— hidden state probe / decoding stage failure；§3 cross-capability
- **关联 paper_planning anchor**: seeing but not believing；hidden state probe；decoding stage failure；cross-capability robustness
- **方法/结果**: 提出 VLM Reliability Probe (VRP)，跨多个 VLM 家族系统检验"注意力-置信度假设"。引入结构化注意力度量（聚类数 C_k、空间熵 H_s）并追踪其跨层演化 ΔH_s。发现"Symbolic Detachment"：模型常"Early Lock"视觉特征，随后注意力扩散，切断早期感知与最终生成。空间注意力与准确率几乎零相关 (R≈0.001)，而 self-consistency (生成路径间一致率) 是真值的主导预测因子 (R=0.429)。因果干预揭示架构分歧：LLaVA 在脆弱的后期瓶颈锁定预测，PaliGemma / Qwen2-VL 将可靠性全局分布，即使摧毁 ~50% 最预测层仍稳健。结论：当前 VLM 的可靠性信号与视觉 grounding map 脱钩，应从生成时动力学与 hidden-state probe 推断。
- **Authors**: Logan Mann, Yi Xia, Ajit Saravanan, Ishan Dave, Saadullah Ismail, Shikhar Shiromani
- **Date**: 2026-06-16 | **arXiv ID**: 2606.17389
- **备注**: 几乎是 P79 phantom space 的实证 sibling——"看到 ≠ 能可靠输出"。其跨架构分歧 (late bottleneck vs global distribution) 可与 P79 的 cross-capability robustness 直接对比；self-consistency 主导真值预测这一点，对 P79 选路由信号 (verbal AUROC vs sampling) 有直接启示。

### [Vernier: Probing Representational Misalignment Behind Lexical Gaps in Causal Reasoning](https://arxiv.org/abs/2606.15733)
- **TL;DR**: 因果推理的词汇表面变化不丢信息，是 read-out 错配
- **关联 narrative**: mid-layer mechanism —— "知道但说不出"的因果定位
- **关联 paper §**: §5 (mechanism) —— knows but cannot say；hidden state probe
- **关联 paper_planning anchor**: knows but cannot say；hidden state probe；activation patching；decoding stage failure
- **方法/结果**: 指令微调 LLM 对同一因果推理题，仅把英文变量名换成类型保持的占位符，答案就变（结构与金答案未变）。问题：这是占位符视图的信息丢失，还是表征仍含答案内容但 read-out 错配？Vernier 用 paired-view 权重更新做工具变量，检查 gap 闭合后的机制。证据支持表征错配：变量名 probe 在占位符视图上变准；activation patching（把某一层激活换掉看输出怎么变）on Qwen-7B / Qwen-14B / Llama-3.1-8B 显示 decision-token 表征能在视图间传递答案身份。闭合 gap 的更新是对原/占位符 prompt 的反事实增强，而 answer-subspace KL 主要锐化中间 answer-belief 一致性。成功受模型家族、规模、任务限制。
- **Authors**: Zhenyu Yu
- **Date**: 2026-06-14 | **arXiv ID**: 2606.15733
- **备注**: 是"knows but cannot say"机制 narrative 的干净单变量实验。其 activation patching + decision-token 传递可为 P79 的 hidden state probe / decoding stage failure 分析提供方法模板；"成功受规模限制"这一点提示 P79 在不同 backbone 上结果可能不一致。

## Score 2 (related work / baseline / failure-mode contrast)

- **[Speaking in Self-Assessing Tongues: On the Verbalized Confidence of LLMs in Machine Translation](https://arxiv.org/abs/2606.17234)** (Marashian, Palmer, von der Wense; 2606.17234) — 设计五种 verbalized 置信度提取方法，与内部信号 (预测概率) 比较。关键发现：内部与 verbalized 方法表现相近但二者几乎无相关 (little to no correlation)，且内部信号反映的是"候选间确定性"而非正确性。命中 L1 verbal confidence。直接关系到 P79 选哪个置信度信号做路由/abstain——内部 logprob 与 verbal confidence 不是同一回事，不可互换。

- **[EARS: Explanatory Abstention for Reliable Sub-Agent Modeling in Large-scale Multi-Agent Systems](https://arxiv.org/abs/2606.18668)** (Xie, Lu, Li, Wang; 2606.18668) — 把 sub-agent abstention 重构为 agent 间通信协议：sub-agent 不只弃答，而是向 coordinator 暴露可操作的失败状态。用 calibrated LLM-as-Judge 集成标注失败模式，微调 sub-agent 检测失败并返回 rationale 供 coordinator 澄清/重路由/fallback。生产电商助手 pass rate 68.5%→78.9%。命中 L1 cascade routing + abstention。为 P79 的"高危动作升级/重路由"提供 abstention-as-signal 的工程参照。

- **[Focus When Necessary: Adaptive Routing and Collaborative Grounding for Training-Free Visual Grounding (LazyMCoT)](https://arxiv.org/abs/2606.16158)** (Wang, Li, Li, Hu, Yang, Yang; 2606.16158; code TencentBAC/LazyMCoT) — 训练-free 框架，用单次前向的 first-token 统计估预测不确定度做 Adaptive Routing：confident 案例直接 bypass，难例走 conformal calibration 召回 + 协同 grounding (模型 cross-modal attention + 外部视觉专家两阶段精修)。命中 L1 confidence routing + L3 GUI grounding。与 P79 的 cost-aware routing + 困难升级机制高度同构。

- **[Beyond Domains: Reusing Web Skills via Transferable Interaction Patterns (SkillMigrator)](https://arxiv.org/abs/2606.17645)** (He, Cui, Wu, Ma, Lu, Li; 2606.17645) — web agent 把重复交互片段封装为 web skill，按页面 layout 结构 (而非元素引用或指令相似度) 跨站迁移。存为 transferable interaction pattern (TIP)，测试时按 layout 相似度检索并在活页上 grounding。WebArena / Mind2Web 上成功轨迹平均 LLM-action 数降 8-10%，成功率持平。命中 L2 web agent + cost。"policy-facing LLM completions dominate latency and cost" 正是 P79 的 4-fold cost dimension 现场。

- **[Cascaded Sparse Autoencoders Learn Multi-Level Visual Concepts in Multimodal LLMs](https://arxiv.org/abs/2606.16193)** (Zhao, Wang, Ganu, Nambi, Wang; 2606.16193) — 提出 cascaded SAE (CSAE)：在一级 SAE 的 decoder 权重上直接训二级 SAE，学"概念的层级"，避免 nesting/stacking 的耦合与瓶颈。Qwen3-VL / Gemma-3 / LLaVA 上层级概念一致性优于 SOTA SAE；concept steering 验证学到的概念组支持组级干预。命中 L0 steering vector + mechanism。为 P79 在 VLM 上做层级机制分析与 steering 干预提供可迁移方法。
