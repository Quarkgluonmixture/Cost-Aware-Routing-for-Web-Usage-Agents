## Score 3 (paper-引用候选)

### [Detect Before You Leap: Mirage Detection in Vision-Language Models](https://arxiv.org/abs/2606.00435)
- **TL;DR** (50 chars): 在 VLM 生成前检测 mirage，3-class 准确率 94.7%
- **RELATION**: SUPPORT — 直接佐证 mirage effect 的可检测性，为 P79 phantom routing 的 confidence signal 提供独立验证
- **命中 LIVE claim / §**: §3 definition (mirage effect 的 pre-release detection), §4 empirical (phantom arm 的 confidence 可用于 routing)
- **关联 paper_planning anchor**: from: Mirage / Confidence Routing
- **Authors**: Sayeed Shafayet Chowdhury, Md. Shaown Miah
- **Date**: 2026-05-29, **arXiv ID**: 2606.00435
- **关键发现**: 提出 TC-LIA（Text-Conditioned Layer-wise Internal Alignment）——一个 model-agnostic 的方法，通过逐层追踪 CLIP ViT 中 patch token 与 question embedding 的对齐轨迹来判断 VLM 是否该 abstain。在 12 个 VLM backbone 上测试，Qwen2.5-VL-32B 达到 94.7% 的三分类检测准确率，mirage rate < 3%。这直接证明了 VLM 内部的 layer-wise alignment trajectory 包含可观的 mirage/confidence 信号。
- **P79 对接**: TC-LIA 的 layer-wise alignment trajectory 特征（final cosine sim + late-layer top-k alignment + early-to-late gain + layer-wise slope）可以直接作为 P79 §6 router 的输入特征。如果 P79 的 phantom format 条件下这些 alignment 特征在不同 arm 之间有系统性差异，这就从 mechanism 层面解释了为什么 text-only arm 在某些条件下 confidence 反而更高——因为 text path 的 alignment trajectory 更早完成对齐。
- **Domain mismatch / 外推风险**: 主要在 medical/general VQA 上验证，非 web agent。但 core mechanism（layer-wise text-image alignment trajectory 预测 output reliability）与 P79 的 phantom format × confidence 轴直接对齐。

### [BoundaryRouter: Learning Agent Routing From Early Experience](https://arxiv.org/abs/2605.07180)
- **TL;DR** (50 chars): Training-free router 在 LLM 和 agent 之间按 query 路由
- **RELATION**: DESIGN-INPUT — 直接为 P79 §6 router 提供 training-free routing 范式
- **命中 LIVE claim / §**: §6 router (cost-aware routing 设计), §4 empirical (不同 observation format 的 routing 效果)
- **关联 paper_planning anchor**: from: Cost-Aware Router / RouteLLM
- **Authors**: Yimin Wang, Jiahao Qiu, Xuan Qi, Xinzhe Juan, Jingzhe Shi, Zelin Zhao, Hongru Wang, Shilong Liu, Mengdi Wang
- **Date**: 2026-05-08, **arXiv ID**: 2605.07180
- **关键发现**: BoundaryRouter 是一个 training-free routing framework，通过在 seed set 上运行 LLM 和 agent 两套系统构建 compact experience memory，然后用 case-based reasoning 做 routing decision。推理时间比纯 agent 减少 60.6%，性能比纯 LLM 提升 28.6%。关键是它处理了 realistic cold-start setting，不需要额外的训练数据。
- **P79 对接**: P79 §6 的 LR router 如果用 BoundaryRouter 的 experience memory + rubric-guided reasoning 范式，可以避免 RouteLLM 的 supervised training 依赖。而且 BoundaryRouter 的 RouteBench benchmark（in-domain / paraphrased / OOD）可以直接用于评估 P79 phantom format router 的泛化能力。OOD 场景下的 performance drop 是 P79 reviewer 会关注的问题。
- **Domain mismatch / 外推风险**: 他们的 routing 是在 "LLM vs agent" 之间做 binary choice，P79 是在多 observation format 之间做 routing。但 framework 的 training-free + cold-start 特性直接适用于 P79 的 setting。

## Score 2 (related work)

### [Revisiting Observation Reduction for Web Agents: Comprehensive Evaluation with a Lightweight Framework](https://arxiv.org/abs/2605.29397)
- **TL;DR**: Minimal Failure Set (MFS) 做为 observation reduction 的 proxy metric，100x 评测加速
- **RELATION**: DESIGN-INPUT — MFS proxy metric 可吸收进 P79 §4 experimental design
- **关键词命中**: accessibility tree, HTML reduction, web agent observation (L0/L2)
- **Authors**: Masafumi Enomoto, Ryoma Obara, Haochen Zhang, Masafumi Oyamada | **Date**: 2026-05-28 | **arXiv ID**: 2605.29397
- **P79 对接**: MFS (Minimal Failure Set) 的概念——即 HTML 中最小的、删掉就会导致任务失败的元素集合——可以直接用在 P79 §4 phantom arms 的 analysis 中。如果 P79 的 AXTree arm 已经覆盖了 MFS 的大部分元素，那 phantom effect 的 "text-only works" 就有了 structural explanation。而且他们的 2.2x latency reduction + 84% success retention 为 P79 §6 cost analysis 提供了独立工程数据。

### [Web Agents Should Adopt the Plan-Then-Execute Paradigm](https://arxiv.org/abs/2605.14290)
- **TL;DR**: Web agent 默认应该用 plan-then-execute 而非 ReAct，80% WebArena 任务可纯程序化完成
- **RELATION**: THREAT + RELATED-ONLY — 如果 plan-then-execute 成为 web agent 新范式，phantom format routing 的 relevance 可能降低（因为 runtime observation 的影响被 plan 阶段隔离了）。但同时也说明 observation format 在 planning 阶段仍然重要。
- **关键词命中**: web agent architecture, observation, ReAct (L2)
- **Authors**: Julien Piet, Annabella Chow, Yiwei Hou, Muxi Lyu, Sylvie Venuto, Jinhao Zhu, Raluca Ada Popa, David Wagner | **Date**: 2026-05-14 | **arXiv ID**: 2605.14290
- **P79 对接**: 这篇的核心 argument（"web tasks 不需要 runtime reactivity，需要 typed, complete, auditable APIs"）对 P79 有双面影响。一方面，如果 plan-then-execute 成为主流，runtime observation format（phantom 的核心变量）的重要性下降——这是 THREAT。另一方面，plan 阶段仍然需要 observation 来做 planning，而且他们的 security argument（untrusted content 不应进入 control flow）恰好支持 P79 "text-only DOM observation 可能更安全" 的 narrative。

### [Explainable Model Routing for Agentic Workflows (Topaz)](https://arxiv.org/abs/2604.03527)
- **TL;DR**: Topaz framework 让 agentic routing 可审计，skill-based profiling + traceable routing
- **RELATION**: DESIGN-INPUT — §6 router 的 interpretability 参考
- **关键词命中**: model routing, cost-aware, agentic workflow (L1)
- **Authors**: Mika Okamoto, Ansel Kaplan Erol, Mark Riedl | **Date**: 2026-04-04 | **arXiv ID**: 2604.03527 | **Venue**: ACM CHI 2026 HCXAI Workshop (Spotlight)
- **P79 对接**: Topaz 的 skill-based profiling + budget-based multi-objective optimization 的做法和 P79 §6 的 LR router 思路类似，但他们多了 natural language explanation layer。如果 P79 的 reviewer 问 "你的 router 可解释性如何"，Topaz 的 inherent interpretability approach（不是 post-hoc explanation）可以作为对比基准。
