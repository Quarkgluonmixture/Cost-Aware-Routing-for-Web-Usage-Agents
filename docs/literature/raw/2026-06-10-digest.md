## Score 3 (paper-引用候选)

### [WebChallenger: A Reliable and Efficient Generalist Web Agent](https://arxiv.org/abs/2606.10423)
- **TL;DR** (50 chars): PageMem + divide-and-conquer observation pipeline 做通用 web agent
- **RELATION**: SUPPORT + DESIGN-INPUT — 直接为 P79 §3 observation format 和 §4 empirical 提供最直接的同类 work
- **命中 LIVE claim / §**: §3 definition (structured observation representation), §4 empirical (observation format 对 performance 的影响), §6 router (model capability × observation detail 的交互)
- **关联 paper_planning anchor**: from: Cost-Aware Router / Observation Format
- **Authors**: Jayoo Hwang (ML Collective), Xiaowen Zhang (longsurf.ai), Vedant Padwal (Independent)
- **Date**: 2026-06-09, **arXiv ID**: 2606.10423
- **关键发现**: WebChallenger 用纯架构设计（无 fine-tuning）在 WebArena 56.3%、VisualWebArena 48.7%、Online-Mind2Web 51.0%、WorkArena 70.9%，接近 OpenAI CUA 等闭源系统。核心是 PageMem——从 DOM 确定性构建的四层 hierarchy（Website → Page → Section → Element），每个 section 有一句话 VLM summary。基于 PageMem，divide-and-conquer observation pipeline 将每步 prompt 从平均 8,793 tokens 压缩到 1,850 tokens，步骤数从 11.26 降到 7.20。三个 cognitive advantage 的 engineering analog：selective attention（section selection + detail extraction），persistent memory（offline exploration 构建 WebsiteMem，跨 task 复用），procedural fluency（compound action workflows 将多步交互折叠为单步）。
- **P79 对接**: WebChallenger 的 PageMem 本质上是一种 structured text observation format，与 P79 的 AXTree arm 直接对应。关键发现是 observation 的结构化程度（section-level summary + selective detail extraction）比 raw DOM token count 更能预测 performance——这与 P79 phantom format 实验的核心 claim 一致。divide-and-conquer pipeline 的三阶段（section selection → detail extraction → summary synthesis）直接为 P79 §6 router 提供了一种 observation-level routing 方案：router 可以在 section selection 阶段就决定哪些 observation element 需要视觉 grounding。而且 PageMem 的"VLM 只在 summary 生成和 image description 时调用"的设计与 P79 "phantom arm 不需要 visual input"的 claim 结构对齐。
- **Domain mismatch / 外推风险**: WebChallenger 使用 GLM-4-32B + Qwen2.5-VL-7B 双模型架构，P79 的 phantom experiment 是单模型不同 observation format。WebChallenger 的 offline exploration 假设网站结构可预先遍历，不适用于 P79 关注的 one-shot/no-prior-knowledge setting。PageMem 的 construction 依赖 DOM heuristics（tag list、size threshold），在 SPA/dynamic content 上可能失效。

## Score 2 (related work)

### [Signal-Driven Observation for Long-Horizon Web Agents (SDO)](https://arxiv.org/abs/2606.06708)
- **TL;DR**: Web agent observation frequency 与 action frequency 解耦，只在 signal 触发时重新读取 DOM
- **RELATION**: DESIGN-INPUT — SDO 的 "observation is an architectural decision" argument 直接支持 P79 §3 将 observation format 作为 first-class design variable
- **关键词命中**: web agent, observation compression, DOM, accessibility tree (L0)
- **Authors**: Shubham Gaur, Ian Lane | **Date**: 2026-06-04 | **arXiv ID**: 2606.06708
- **P79 对接**: SDO 提出 observation frequency 应独立于 action frequency，这与 P79 的 phantom format 实验从不同角度触及同一问题——observation 不是每步都需要的。SDO 的 signal detector（URL 变化、新交互元素出现、action 失败）可以作为 P79 §6 router 的 routing feature：当 signal 未触发时使用 phantom arm（text-only），signal 触发时 fallback 到 full-observation arm。但 SDO 是 position paper，无量化的 ablation 结果，理论贡献大于实验贡献。

### [Subspace-Aware Sparse Autoencoders (SASA)](https://arxiv.org/abs/2606.06333)
- **TL;DR**: 证明 standard SAE 的 feature splitting 是必然的（exponential in feature dimension），提出 subspace decoder 修复
- **RELATION**: DESIGN-INPUT — SASA 直接影响 P79 §5 activation patching 中 SAE 的选择和使用方式
- **关键词命中**: SAE, sparse autoencoder, feature splitting, mechanistic interpretability (L0)
- **Authors**: Seyed Arshan Dalili, Mehrdad Mahdavi | **Date**: 2026-06-04 | **arXiv ID**: 2606.06333
- **P79 对接**: P79 §5 如果使用 SAE 做 activation analysis，standard SAE 的 feature splitting 会产生大量 near-collinear latents，使得 phantom vs full-observation 条件下的 feature comparison 变得 noise。SASA 的理论证明（ℓ₁ regularization actively causes splitting）和 empirical 改进（GPT-2 + Mistral-7B，~50% token budget）意味着 P79 应该考虑用 SASA 替代 standard SAE。但 SASA 目前只在 LLM（非 VLM）上验证，且未在 agent/grounding 场景测试。

### [Dual-Pathway Circuits of Object Hallucination in VLMs](https://arxiv.org/abs/2605.13156)
- **TL;DR**: 五个 VLM 中发现 grounding pathway 和 hallucination pathway，抑制 hallucination pathway 减少 76% hallucination
- **RELATION**: SUPPORT — 直接佐证 P79 §5 的 circuit-level analysis 可行性，polarity flip 现象与 phantom effect 的 mechanism 相关
- **关键词命中**: activation patching, VLM hallucination, circuit analysis, pathway (L0)
- **Authors**: Jiaxin Liu, Ding Zhong, Yue Wang 等 | **Date**: 2026-05-13 | **arXiv ID**: 2605.13156
- **P79 对接**: Dual-Pathway 发现 grounding components 在正确和错误样本中均存在（redundant），但 polarity 方向翻转。这与 P79 phantom format 的核心问题对齐：model 内部同时存在 visual grounding circuit 和 language-prior circuit，phantom effect 可能是 language-prior circuit 在缺少 visual input 时 dominant。targeted suppression 减少 76% hallucination 说明 circuit intervention 是有效的，支持 P79 §5 用 activation patching 做 phantom mechanism 分析的方法论。但验证在 object hallucination（POPE/AMBER）上进行，非 web agent grounding。
