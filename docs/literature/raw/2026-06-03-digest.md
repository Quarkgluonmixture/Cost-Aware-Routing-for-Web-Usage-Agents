## Score 3 (paper-引用候选)

### [The Scaffold Effect: How Prompt Framing Drives Apparent Multimodal Gains in Clinical VLM Evaluation](https://arxiv.org/abs/2603.28387)
- **TL;DR** (50 chars): Prompt framing alone inflates clinical VLM accuracy up to 58% F1
- **RELATION**: SUPPORT — 直接佐证 scaffold effect 现象：仅 prompt 格式变化就产生虚高的多模态增益
- **命中 LIVE claim / §**: §3 definition (scaffold effect 定义), §4 empirical (phantom format 对比实验的可信度)
- **关联 paper_planning anchor**: from: Scaffold Effect
- **Authors**: Doan Nam Long Vu, Simone Balloccu
- **Date**: 2026-03-30, **arXiv ID**: 2603.28387
- **关键发现**: 12 个 VLM 在神经影像任务上测试，MRI 数据本身不含诊断信号，但 prompt 中提及 "MRI 可用" 就造成 70-80% 的性能提升。RLHF 后模型不再提及 MRI，但性能也跌回随机基线——说明 safety alignment 和 genuine multimodal reasoning 之间存在 tradeoff。
- **Domain mismatch / 外推风险**: 临床神经影像 ≠ web agent。VLM 在医学图像上的 modality collapse 行为是否可外推到 web screenshot 场景需要验证。但核心机制（prompt framing 驱动虚假增益）与 P79 的 phantom 轴 (format × decision-style) 直接对齐。

### [MIRAGE: The Illusion of Visual Understanding](https://arxiv.org/abs/2603.21687)
- **TL;DR** (50 chars): Frontier VLMs ace multimodal benchmarks with zero images
- **RELATION**: SUPPORT — 直接佐证 mirage effect 现象：VLM 在没有图像输入时仍获得高分
- **命中 LIVE claim / §**: §3 definition (mirage effect 定义), §4 empirical (text-only arm 的竞争力)
- **关联 paper_planning anchor**: from: Mirage
- **Authors**: Mohammad Asadi, Jack W. O'Sullivan, Fang Cao, Tahoura Nedaee, Kamyar Rajabalifardi, Fei-Fei Li, Ehsan Adeli, Euan Ashley
- **Date**: 2026-03-23 (v1), **arXiv ID**: 2603.21687
- **关键发现**: (1) "mirage reasoning"——模型为从未提供过的图像生成详细描述和临床发现；(2) 在 general 和 medical multimodal benchmark 上，无图像模型排名可以登顶；(3) 显式告知模型 "没有图像" vs 隐式让模型假设图像存在，性能差异巨大——说明 implicit prompting regime 下模型的 "视觉推理" 大部分来自语言先验。
- **Domain mismatch / 外推风险**: 主要在医学影像和 general VQA 上验证，非 web agent。但 mirage reasoning 机制（语言先验 dominance → 无图像也能回答）直接支持 P79 的 P-text/P-prompt arm 竞争力发现。Fei-Fei Li 共作者增加了 paper 权重。
- **P79 对接**: 提出的 B-Clean 评估方案（消除 textual cues 以 fair evaluation）可作为 P79 §4 experimental design 的参考。

### [How do LLMs Compute Verbal Confidence?](https://arxiv.org/abs/2603.17839)
- **TL;DR** (50 chars): Confidence is cached at answer position, not computed on demand
- **RELATION**: DESIGN-INPUT — 为 P79 §5 mechanism analysis 提供可直接复用的 activation patching 实验范式
- **命中 LIVE claim / §**: §5 mechanism (activation patching 流水线设计), §4 empirical (verbal AUROC 的内在机制)
- **关联 paper_planning anchor**: from: Tool Calling Linear Circuit / Activation Patching
- **Authors**: Dharshan Kumaran, Arthur Conmy, Federico Barbero, Simon Osindero, Viorica Patraucean, Petar Veličković (DeepMind)
- **Date**: 2026-03-18 (v1), **arXiv ID**: 2603.17839
- **关键发现**: 用 activation patching + attention blocking + linear probing 在 Gemma 3 27B 上追踪 verbal confidence 的信息流。发现 confidence 在 answer-adjacent position 自动缓存（不是被要求时才计算），然后通过 attention 从 cached position 检索到 verbalization site。这说明 LLM 有 genuine self-evaluation 能力，不是 post-hoc 重建。
- **P79 对接价值**: 实验范式 (activation patching + attention blocking + swap experiment) 可以直接移植到 P79 的 phantom format 条件下，追踪 "format information" 的表示在哪些层被编码、如何影响 decision output。如果 P-text 条件下某个 mid-layer 的 format representation 和 P-SoM 条件下的差异最大，这直接解释 phantom routing 的 mechanism。

## Score 2 (related work)

### [Steered LLM Activations are Non-Surjective](https://arxiv.org/abs/2604.09839)
- **TL;DR**: Steering pushes residual stream off natural manifold; no prompt reproduces it
- **RELATION**: THREAT — 可被 reviewer 用来质疑 P79 §5 activation patching 结果的 ecological validity
- **关键词命中**: activation patching, steering vector (L0)
- **Authors**: Aayush Mishra, Daniel Khashabi, Anqi Liu | **Date**: 2026-04-10 | **arXiv ID**: 2604.09839
- **Reviewer-预案**: 如果 P79 的 activation patching 修改了 activation 后声称这反映了 natural computation，这篇 paper 证明了 steered activation 不可被任何 prompt 重建——即 patching 结果不一定 generalize 到 natural forward pass。P79 应在 §5 limitations 中明确区分 "patching 干预揭示的 causal role" vs "natural condition 下的 information flow"。

### [Zero-Shot Confidence Estimation for Small LLMs](https://arxiv.org/abs/2605.02241)
- **TL;DR**: Zero-shot token log-prob matches supervised RouteLLM baselines for routing
- **RELATION**: DESIGN-INPUT (§6 router) — 零训练 confidence signal 可替代 supervised router
- **关键词命中**: RouteLLM, confidence routing, AUROC (L1)
- **Authors**: Luong N. Nguyen | **Date**: 2026-05-04 | **arXiv ID**: 2605.02241
- **P79 对接**: P79 §6 的 LR router 如果用 zero-shot log-prob 做 confidence feature，可能无需额外训练数据。OOD AUROC 0.717-0.833 比 supervised 0.512-0.564 好——说明 phantom routing 的 confidence signal 在分布外场景更鲁棒。

### [Sema: Semantic Transport for Real-Time Multimodal Agents](https://arxiv.org/abs/2604.20940)
- **TL;DR**: A11y tree + compact visual tokens replaces raw screenshots with <0.7pp accuracy loss
- **RELATION**: DESIGN-INPUT — 混合表示 (a11y tree + visual tokens) 验证了 P79 P-text arm 的可行性
- **关键词命中**: accessibility tree, screen representation (L0)
- **Authors**: Jiaying Meng, Bojie Li | **Date**: 2026-04-22 | **arXiv ID**: 2604.20940
- **P79 对接**: Sema 的 hybrid representation (lossless a11y-tree + compact visual tokens) 和 P79 的 phantom arm 设计高度吻合。带宽减少 130-210x，任务准确率损失 <0.7pp——为 P79 的 cost≈DOM claim 提供了独立工程验证。

### [SteerMoE: Steering MoE LLMs via Expert (De)Activation](https://arxiv.org/abs/2509.09660)
- **TL;DR**: Detect & control behavior-linked MoE experts at inference time, no fine-tuning
- **RELATION**: RELATED-ONLY — expert routing 的可解释性对 P79 router 有参考价值但不直接
- **关键词命中**: SteerMoE, expert routing, alignment faking (L0)
- **Authors**: Mohsen Fayyaz et al. (Adobe Research / LMU / UCLA) | **Date**: 2025-09-11, ICLR 2026 | **arXiv ID**: 2509.09660
- **P79 对接**: MoE expert 的 (de)activation 和 P79 router 的 task-level mode selection 有结构相似性。alignment faking 发现（safety training 集中在部分 expert subsets）提醒 P79 在分析 phantom format 对齐时注意 safety-critical expert 的覆盖。
