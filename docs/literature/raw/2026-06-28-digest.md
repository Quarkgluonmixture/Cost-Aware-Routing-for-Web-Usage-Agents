## Score 3 (paper 引用候选)

### [When AUC 0.998 Is Not Enough: A Candidate Evaluation Protocol for Hidden-State Probes of Indirect Prompt Injection in Multimodal Computer-Use Agents](https://arxiv.org/abs/2606.22864)
- **TL;DR**: 高 probe AUC ≠ 真检测到恶意内容，需控制集
- **RELATION**: THREAT + DESIGN-INPUT — 直接威胁 P79 基于 probe-AUC 的 §5 机制结论，同时提供可吸收的控制集方法
- **命中 LIVE claim / §**: §5 (mechanism — hidden state probe / linear probe 方法论)；§4-limitations-disclosure（probe 报告协议）
- **关联 paper_planning anchor**: hidden state probe；linear probe；knows but cannot say；tool spoofing
- **方法/结果**: 在 Qwen2.5-VL-7B + Mind2Web（teacher-forced replay）上做单 backbone 警示案例：用 frozen VLM 内部激活上的线性分类器（hidden-state probing）标记 indirect prompt injection。指出 clean-vs-attack split 上的高 AUC 本身不构成"检测到恶意内容"的证据。给两个 post-hoc 诊断：text-side injection 的 paired-construction scalar baseline，overlay surface 的 same-step nuisance-matched visual controls。打包成"候选控制集"+ 报告启发式，说明高 AUC 能/不能 license 什么。标签是 injection-surface-present 而非 attack-success；跨 backbone/benchmark 泛化是 conjecture。
- **THREAT reviewer-预案要点**: hostile reviewer 可援引此文质疑 P79 §5 的 probe-AUC 机制结论存在同样的 nuisance confound。P79 应在 mechanism 实验里主动加 nuisance-matched 视觉控制与 scalar baseline，并在 §4-limitations 报告 probe 能/不能 license 的范围，提前堵掉这条攻击线。
- **Authors**: Yanhang Li, Zhichao Fan, Zexin Zhuang
- **Date**: 2026-06-22 | **arXiv ID**: 2606.22864
- **备注**: 与 P79 同域（multimodal CUA + Mind2Web + hidden-state probe），是本轮最硬的命中。其单 backbone 谦逊姿态值得 P79 效仿——不要 over-claim probe 的语义解读。

## Score 2 (related work / design-input)

- **[Beyond Logprobs: A Multi-Signal Confidence Engine for LLM-Based Document Field Extraction](https://arxiv.org/abs/2606.24420)** (Nitesh Kumar; 2606.24420) — 关键发现：token-logprobs、verbalized confidence、multi-sample self-consistency 在实用阈值下"都塌缩成全正"，无法区分可信/不可信。提出 ExtractConf，用两种结构化读法（field-guided Hunter vs document-guided Mapper）的 disagreement 作信号，融合 OCR/图像质量/空间布局训分类器。命中 L1 calibration / 置信度路由。**外推风险**：域是文档抽取非 web agent；但"Hunter vs Mapper 两种读法的分歧即信号"与 P79 phantom 三臂（同页不同 format 表征的分歧可作路由信号）高度同构，是 §6 router 的 DESIGN-INPUT；"常见置信度信号塌缩"是对 router 选信号的 THREAT/caution。

- **[Just how sure are you? Improving Verbalized Uncertainty Calibration in Medical VQA](https://arxiv.org/abs/2606.27023)** (Senoglu, Toschi, Brunello, Sassella, Carman; 2606.27023) — 训练式校准 medical VQA 的 verbalized confidence；核心方法 2×2 factorial 扰动（image presence × text integrity）探模型依赖视觉还是语言先验，配合 Brier + anchor + contrastive + KL 复合 loss。MedGemma-4B / Qwen2-VL-7B 上校准误差降 60%+、判别力 +26%+。命中 L1 verbal confidence + L0 language prior dominance。**外推风险**：medical VQA 非 web agent；但 factorial image×text 扰动探"视觉 vs 语言先验依赖"是 P79 §5 mechanism 的可迁移方法，校准 loss 对 §6 router 的 verbal AUROC 信号有直接参照。

- **[Adaptive Re-Ranking](https://arxiv.org/abs/2606.25249)** (Genc, Korukluoglu, Allan; 2606.25249) — cost-aware per-query routing 在 BM25 / MiniLM / BGE 三档间路由，给 oracle 分析 + 训练 router。诚实结论："per-query 路由潜在收益大，但有限监督下非平凡难学"。命中 L1 cost-aware routing。**外推风险**：IR re-ranking 非 web agent；但 oracle gap + router 可学性分析是 P79 §6 router + §4 empirical（drop-one oracle）的干净同构参照，"非平凡难学"直接进 §4-limitations。

- **[The Geometry of Refusal: Linear Instability in Safety-Aligned LLMs](https://arxiv.org/abs/2606.22686)** (Ratnakar, Vats; 2606.22686) — Contrastive Logit Steering (CLS) 在 output distribution 上隔离 refusal direction，揭示架构决定性：Llama-3.1 呈"Late Decision"（易绕过，~1s 达 95% ASR）vs Qwen-2.5 呈"Early Divergence"（中途整合安全）。命中 L0 steering vector / linear steerable。**外推风险**：纯文本 LLM 安全对齐，非 web/VLM 路由；但"决策在模型哪一层/阶段形成"的拓扑分析（Late vs Early）是 P79 §5 mechanism（decoding stage failure / mid-layer）的方法 DESIGN-INPUT。
