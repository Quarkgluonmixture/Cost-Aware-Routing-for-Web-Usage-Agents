## Claims worth carrying (verbatim gist)

1. Claude `computer_toolset_20260801` is screenshot-native: screenshot → model → click(x,y)/type/scroll → fresh screenshot; no AX path inside Computer Use. The AX/ref path lives in `browser_toolset_20260801` (`read_page`, `find`, `get_page_text`, `form_input`, element refs, plus screenshot/coordinate click). Anthropic's own guidance orders interfaces: specific API/tool → Browser Use → Computer Use ("most general, also most slow").
2. Inside Browser Use the choice between `read_page`/ref actions and screenshot/coordinate actions is **model tool selection**; no published threshold, classifier, cost model, or learned router.
3. OpenAI API / native CUA (through GPT-5.4 and the Responses `computer` tool) is pixel-native: action schema is click/double_click/drag with x,y; outputs are `computer_tool_call_output_screenshot`; no public accessibility node ids.
4. Codex Desktop Computer Use (`@oai/sky`, `SkyComputerUseService`) exposes `get_app_state` / `get_window_state` returning accessibility text AND screenshot, independently switchable (`include_text`, `include_screenshot`), and semantic actions (`click_element(index)`, `set_value`) alongside `click(x,y)`/`drag`. Community reading of the bundled skill: accessibility elements first, screenshot coordinates as fallback. Evidence grade: GitHub issues + a third-party bridge, not an OpenAI architecture spec.
5. Codex often returns AX + screenshot together by default ("AX + Vision always-ish, model decides"), and has produced desynchronised pairs (Paint UIA tree + Windows lock-screen pixels; Explorer AX + Codex-window screenshot) ⇒ a hybrid needs a cross-modal freshness/identity gate, not only a router.
6. September: a `unified-computer-use` facade registering `@oai/browser-desktop/service` and `@oai/sky/service` together; still unstable.
7. Bottom line as supplied: Claude routes at the toolset level (task-level interface choice); Codex Desktop routes inside one CU runtime; **neither publishes a cost-aware per-step router** — the choice is made by the frontier model under skill/prompt instructions.
