WHAT THIS WITNESS DOES *NOT* CLAIM
==================================
Unlike AMENDMENT 01-07, this witness does NOT precede the data. All 36 Pass-1
conditions (18 reddit + 18 classifieds) had landed and been analysed before the
exclusion criteria were written. The effect on pooled SR was known to the author at
authoring time. HARKing-adjacent; disclosed as such in AMENDMENT_08 §0 rather than
framed as a pre-data lock.

What the tag DOES anchor: the boundary before which no reddit analysis artifact had
been regenerated under the post-amendment scored-task universe. Every reddit artifact
carrying the pre-amendment universe SHA 41b1a918356a563c... is stale as of this commit.

EXCLUDED TASKS
==============
reddit 160 — tier A (config-derivable, outcome-blind). program_html eval carrying only
  `must_exclude` and no positive check: doing nothing scores 1, so the eval cannot
  separate a completed task from an untouched one. Uniform rule over all 210 reddit
  tasks; task 160 is the sole match. Same defect class as the §139.8 N/A exclusion with
  the sign flipped (trivially passable vs un-passable).

reddit 58 — tier B (config-suggestive, trajectory-confirmed). Cross-site task
  (`sites: [wikipedia, reddit]`) whose exact_match reference "Reki Kawahara" is
  recoverable from parametric knowledge. Uniform rule over all 40 cross-site reddit
  tasks — "successes that never load a declared second site" — selects exactly this
  one: 9 of the 11 cross-site successes across the 18 conditions, 0 of those 9 loading
  localhost:8888, vs 2/2 for the other two solvable cross-site tasks (49, 66).
  Wikipedia was reachable throughout (2265 steps landed on it), so this is a task
  property, not an environment gap. Weaker warrant than tier A and reported as its own
  sensitivity arm.

H1 HERO EXPOSURE — the direction check
======================================
The drop-one oracle only moves if an excluded task was solved by exactly one mode in a
cell. Of the 6 exposure points (3 models x 2 tasks), exactly ONE qualifies:
reddit/B2 task 58, solved only by phantom_som. The amendment therefore subtracts
drop-one credit from the paper's hero arm, in the one cell where it changes the hero
metric at all. An exclusion reverse-engineered to help would not do that.
