# Mechanism Case Studies for Section 5

Source: `docs/analysis/cross_sites/mechanism_per_task.json` E2 case lists plus per-episode `*_steps_v2.jsonl` traces. I used B0 traces for the eight E2 contrasts and added B1 classifieds checks where the same task exposes the new P-SoM ~= DOM result. Skipped reddit task 7 for the P-text vs Phantom-SoM paragraph because the P-text trace has only four steps; reddit task 167 is the replacement from the same E2 candidate list with sufficient steps.

**Case 1 - classifieds task #201: DOM vs P-text**
Intent: show the latest listing of a snare drum with a black and red color scheme. DOM failed after a plausible but brittle search loop: it typed `snare drum black red`, paged to `http://100.95.81.103:9980/index.php?page=search&sPattern=snare+drum+black+red+&iPage=2` at step 5, then repeatedly scrolled page 2 through step 11 with `no_progress`. P-text succeeded by following the same first-page path through step 6, then taking a qualitatively different branch at step 7: it clicked into `sCategory=21` for Music instruments, scrolled once, and clicked item `id=50230` after recognizing the title `Vintage 60s red onyx snare drum (rare)`. The divergence is a text-payload/navigation affordance effect: P-text retained enough indexed category structure to switch from blind pagination to a category-constrained search, while DOM stayed in a continuation-page loop.

**Case 2 - classifieds task #201: DOM vs Phantom-SoM**
Intent: same snare-drum target. DOM failed as above by stopping on page 2 after repeated no-progress scrolls. Phantom-SoM also began with `snare drum black red`, but it continued the pagination branch past DOM's boundary: step 10 clicked page 3, step 14 clicked page 4, and step 16 clicked `http://100.95.81.103:9980/index.php?page=item&id=50230`. The decisive step is not image use; Phantom-SoM has no screenshot. It is a prompt and indexed-mark persistence effect: the SoM-style action policy tolerated a longer search frontier and kept using marked pagination/listing controls after scroll failures. B1 makes the limit visible: on the same task, B1 DOM and B1 Phantom-SoM both failed. B1 Phantom-SoM did click `id=50230` at step 4, but then second-guessed the match, searched again, and ended in repeated no-progress type actions. This is useful negative evidence for treating P-SoM as DOM-cost, not as an image substitute.

**Case 3 - classifieds task #103: P-text vs Phantom-SoM**
Intent: browse Arts + crafts and find the most recently listed item portraying the person in the reference image, Abraham Lincoln. P-text selected Arts + crafts, clicked into `sCategory=4`, and then scrolled the category page until no-progress termination; its thoughts repeatedly said to search for `Abraham Lincoln statue`, but it never took a page-navigation or item-click branch. Phantom-SoM followed the same first seven steps, then diverged at step 7 by clicking the next page URL `...page=search&sCategory=4&iPage=2`. After two more scrolls, it selected the listing `bronze Lincoln stands` at step 10 and finished on `...page=item&id=77577`. The root cause is the SoM prompt's stronger commitment to marked controls after a stagnant viewport: the semantic target was present in both traces, but only Phantom-SoM converted "not on this viewport" into an explicit page-2 action.

**Case 4 - classifieds task #17: Phantom-SoM vs SoM**
Intent: show the cheapest bike with red handlebars between $900 and $950. Phantom-SoM failed despite finding the right listing URL early: it searched `bike`, set `sPriceMin=900` and `sPriceMax=950`, clicked `id=79747`, then entered a 30-step back-and-forth loop because the text page did not explicitly confirm red handlebars. SoM succeeded in five steps: it made the same `bike` and price-filter moves, clicked `id=79747`, and finished after visually accepting that the $900 Cannondale matched the red-handlebar requirement. This is the cleanest Axis 3 image-only mechanism on classifieds. The B1 replication is even sharper: B1 DOM failed, B1 Phantom-SoM failed on a different $900 listing (`id=10865`), and B1 SoM succeeded on `id=79747`. The multiplier is the screenshot, not cheaper text.

**Case 5 - reddit task #81: DOM vs P-text**
Intent: upvote every post on the current PhotoshopBattles page whose picture contains a cat. DOM succeeded by combining title semantics and action state. It scrolled, upvoted `PsBattle: cat behind a cat`, then recognized `PsBattle: A cat on snow`, `PsBattle: Cat excited for food`, and `PsBattle: Smiling Kitty`, clicking separate upvote controls through step 5. P-text matched DOM through the first two actions but failed at step 4: after clicking the upvote for `A cat on snow`, it kept clicking the same marked control (`eid=1673`) and received `no_progress` twice. The divergence is an action-state serialization issue. DOM saw enough button-state change (`Upvote` becoming `Retract upvote`) to advance to the next cat post; P-text had the same target vocabulary but collapsed onto a stale repeated click.

**Case 6 - reddit task #7: DOM vs Phantom-SoM**
Intent: navigate to the comment URL of the OP's recipe comment for the image post. DOM failed adjusted scoring after a 30-step search loop: it repeatedly typed variants of `recipe cake with cranberries and rosemary`, hit empty search results, returned to `/forums`, and never reached the target post or comment permalink. Phantom-SoM succeeded in five steps with a broader query. It typed `cake recipe`, saw a search result containing an OP recipe comment, and clicked directly to `http://100.95.81.103:9999/f/food/18987/-/comment/313939`; subsequent clicks stayed on that permalink before finish. The divergence is prompt-induced query breadth plus marked-comment affordance. DOM overfit the visual description into a long exact query; Phantom-SoM treated the task as "find an OP recipe comment" and used the comment permalink as the terminal object.

**Case 7 - reddit task #167: P-text vs Phantom-SoM**
Intent: navigate to the comments section of a post with an image of a dog and a cat. P-text failed by finishing too early on a semantically weak post: after searching `dog and cat`, it clicked `.../f/mildlyinteresting/21550/someone-drew-on-this-section-of-chipped-paint-to-make-it`, scrolled once, and declared that a chipped-paint drawing was enough. Phantom-SoM also searched `dog and cat` and repeatedly clicked the associated image URL `.../submission_images/f26dec04d6672c3779c64d197c88be88f96961bf5dd83620e953bd06560f92d6.jpg`, but it did not prematurely finish. It kept alternating between the image and search results trying to recover a comments page; the adjusted evaluator marks it successful, but the trace shows high-effort uncertainty. The mechanism is a calibration/action-policy shift: P-text converts an ambiguous text title into completion, while Phantom-SoM keeps the navigation objective live longer.

**Case 8 - reddit task #0: Phantom-SoM vs SoM**
Intent: find the shown sushi-platter post and navigate to its comment section. Phantom-SoM succeeded after recovering from the image-link trap. It clicked the sushi image URL three times, backed out each time, then at step 6 clicked the actual post URL `http://100.95.81.103:9999/f/food/82896/i-ate-sushi-platter` and repeatedly targeted the `183 comments` link. SoM failed in the same trap: for all 30 steps it alternated between the sushi image URL and `/f/food`, never taking the post URL branch. This is a counterexample to a naive "image always helps" story. The image made SoM confident about the visual match, but the marked image anchor dominated the action policy. Phantom-SoM's text-only marks eventually exposed the neighboring post/comment link more cleanly than the over-salient image.

**Cross-Axis Synthesis**
Across the eight cases, the shared mechanism is not "better perception" but boundary control after an initially plausible action stops producing evidence. Text-payload and prompt changes mostly alter the next branch after a stale viewport: go to a category (`classifieds #201`), go to the next page (`classifieds #103`), broaden a query (`reddit #7`), advance from one upvote control to the next (`reddit #81`), or keep searching instead of finishing (`reddit #167`). Axis 3 is different because it changes the evidence available for visually grounded predicates. `classifieds #17` shows the positive form: both B0 and B1 text-only traces hesitate because "red handlebars" is not a reliable text field, while SoM finishes from the image. `reddit #0` shows the negative form: the screenshot can over-weight the image anchor and suppress the post/comment URL branch. The B1 observations are consistent with the new aggregate result that B1 P-SoM classifieds (7.69%) is statistically indistinguishable from B1 DOM (8.55%, p=0.73): B1 P-SoM follows DOM-like text loops on `#201` and fails with DOM on `#17`, while B1 SoM succeeds on `#17`. That supports, but does not prove, the hypothesis that Axes 1 and 2 are mostly capability-tier invariant and Axis 3 is the real tier multiplier. Strongest evidence by drop-in property: (a) cost/no-image parity is `#201` B1; (b) trajectory complementarity is `#103`; (c) action-vocabulary/control-state sensitivity is `#81`; (d) image-only lift is `#17`.
