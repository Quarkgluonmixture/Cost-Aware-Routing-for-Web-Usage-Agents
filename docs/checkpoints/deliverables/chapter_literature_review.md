# Chapter 2 — Literature Review

## 2.0 Scope and organisation

This thesis asks whether a web agent's *observation representation* — the textual or visual form in which a browser page is presented to a vision-language model (VLM) — can be treated as a routed, cost-bearing decision variable rather than a fixed configuration choice. Answering that question touches several literatures that are usually studied separately. This chapter reviews them in an order that mirrors the argument of the thesis: the agents and benchmarks that define the setting (§2.1); the observation representations that are the objects being routed (§2.2); routing and cost-aware inference systems, which supply the decision machinery but have so far routed *compute* rather than *representation* (§2.3); prompt-format sensitivity, which makes it plausible that representation is a causal variable at all (§2.4); confidence and uncertainty signals, which a router must consume (§2.5); cost-efficiency techniques specific to web agents, which define the baseline efficiency toolkit (§2.6); and the reliability of web-agent evaluation itself, which constrains what any of the above can claim (§2.7). Section 2.8 positions the present work at the intersection and states the gap precisely.

## 2.1 Web agents and their evaluation environments

A web agent is a language model placed in a closed loop with a browser: at each step it receives an observation of the current page, emits an action (click, type, scroll, navigate, stop), and the environment returns the next page state. The modern evaluation methodology for such agents was largely set by WebArena, which hosts realistic, fully functional replicas of common site categories (e-commerce, forums, collaborative software, maps) and scores agents by *functional correctness* — programmatic checks on the final site state or answer, rather than action-sequence matching \citep{zhou2024webarena}. Mind2Web complements this with a broad corpus of action-selection tasks over snapshots of real websites, emphasising generalisation across sites and domains \citep{deng2023mind2web}.

VisualWebArena (VWA) extends WebArena in the direction this thesis needs: it introduces 910 tasks across three self-hosted sites (classifieds, shopping, a Reddit-style forum) in which task success often depends on *visual* properties of page content — finding the listing whose photo shows a particular object, comparing thumbnail images, or grounding a textual description in a screenshot region \citep{koh2024visualwebarena}. Because the sites are self-hosted, the environment can be reset to a canonical state between conditions, which is what makes controlled cross-representation comparison possible at all; the experimental chapters of this thesis lean heavily on that property. SeeAct, evaluating GPT-4V as a generalist web agent, established an influential diagnosis: performance is strongly bottlenecked by *grounding* — with oracle grounding the model completes substantially more live-web tasks, while automatic grounding remains the major challenge — so the interface between perception and action deserves first-class attention \citep{zheng2024seeact}. WebVoyager carried the same generalist recipe onto the live, open web with multimodal observations and an automatic evaluation protocol \citep{he2024webvoyager}. AgentOccam later showed that simply refining the observation and action space of a baseline agent, with no new models or training, produces large success-rate movements on WebArena \citep{agentoccam2025}; WorkArena makes a similar point for enterprise software tasks \citep{drouin2024workarena}. Early exploratory work on GPT-4V ("The Dawn of LMMs") had already catalogued how strongly multimodal behaviour depends on how inputs are presented \citep{yang2023dawnoflmms}.

Two features of this literature matter for the thesis. First, observation design is *known* to be load-bearing — AgentOccam is direct evidence — yet it is treated as an engineering preliminary: something a system fixes once, before the science starts. None of these benchmarks treats the observation mode as an experimental axis to be measured, costed, and routed per task. Second, the dominant metric is a binary success rate per task, which makes per-task *complementarity* between configurations (task A succeeds under representation X but not Y, task B the reverse) invisible unless explicitly analysed. Both features define the opening for this work.

## 2.2 Observation representations: DOM text, Set-of-Marks, and vision

Three observation families recur across web agents. *DOM/AXTree text* serialises the browser's accessibility tree into hierarchical text: each interactive element appears with a node id, role, and label, nested to reflect page structure. It is cheap (no image tokens), symbolic, and compatible with text-only models, but verbose and blind to visual appearance \citep{zhou2024webarena,deng2023mind2web}. *Vision* sends a raw screenshot and asks the model to act from pixels alone, testing whether visual perception can substitute for symbolic grounding. Between them sits *Set-of-Marks* (SoM) prompting, introduced by Yang et al.: numbered marks are overlaid on image regions so that a multimodal model can refer to visual objects by discrete IDs \citep{yang2023som}. In web agents the SoM observation is a *bundle*: a marked screenshot plus a text legend (here written `[SOM_MARKS]`) mapping mark IDs to element descriptions. The SoM idea has propagated widely — Magma builds SoM-style action grounding into an omni-modal agent foundation model \citep{yang2025magma}, Ferret-UI 2 applies related referring/grounding machinery to UI understanding \citep{li2025ferretui2}, and UGround trains dedicated visual grounding models for GUI agents \citep{zheng2024uground}.

The visual channel these designs rely on is not unconditionally trustworthy. Tong et al. document systematic VLM failures on image pairs that CLIP-style encoders cannot distinguish ("Eyes Wide Shut"), showing that multimodal models inherit blind spots from their visual encoders \citep{tong2024eyes}. A related line documents the converse failure — models answering from linguistic priors while under-using an image that is present \citep{asadi2026mirageillusionvisualunderstanding,kaduri2024whatsintheimage}; the phantom configurations studied in this thesis probe the complementary regime in which the image is deliberately absent. At the agent level, the effect of *removing* a channel can be dramatic: in OpenApps' controlled toy environments, GPT-4o operating vision-only scores 0 on their task suite while the same model with AXTree access scores 82–90 \citep{ullrich2025openapps}. Numbers of that size are environment-specific, but they establish that observation mode is a first-order experimental factor, not a tuning detail.

Across all of this literature, one convention is so uniform that it is easy to miss: the `[SOM_MARKS]` text exists only as an *auxiliary index to the marked image*. To our knowledge — based on arXiv-indexed work as of June 2026 — it has not been isolated as a controlled, standalone observation arm, sent *without* the screenshot it indexes, and compared on equal task pools against DOM, SoM, and Vision. That missing configuration, and its two siblings obtained by crossing text payload with prompt family, form the *phantom routing space* — our coinage, defined formally in Chapter 3 — that this thesis measures. The point is emphatically not that text-only operation is a new artifact — production systems routinely drop images for cost reasons — but that the behaviour of these configurations has not been scientifically characterised: measured for success, cost, latency, signal quality, and task-pool overlap under controls.

## 2.3 Routing and cost-aware inference in LLM systems

### 2.3.1 Model-level routing

Routing emerged as the standard response to heterogeneous cost and capability across models. FrugalGPT frames inference as a cascade over LLM APIs, learning when a cheap model's answer can be accepted and when to escalate \citep{chen2023frugalgpt}. RouteLLM learns routers from human preference data to choose between a weaker and a stronger model under an explicit cost–quality trade-off \citep{ong2025routellm}. A related line halts computation early *within* a model when continued depth is unnecessary \citep{lu2025earlyexit}. These systems established the now-standard framing this thesis inherits: a menu of arms with different cost profiles, a per-input decision, and evaluation on the resulting cost–quality Pareto frontier. What distinguishes the present work is *what the arms are*.

### 2.3.2 Compute routing in agents

A cluster of 2026 systems brings routing into the agent setting, each routing a different *compute* resource. DMR routes numeric precision per step, switching between a bf16 and a quantised variant of the same Qwen3 model (the same backbone family as this thesis's local baseline); a lightweight transformer router is trained first with a KL-divergence-based sensitivity label and then refined with reinforcement learning, and on ALFWorld the routed system slightly exceeds the full-precision baseline at lower cost \citep{li2026dmr}. PANDO routes model *capacity* inside a single VisualWebArena agent — an expensive planner versus a cheap actor — combined with an online skill library, and reports 58.3% success on the full 910-task VWA with 58–61% fewer tokens than comparison systems \citep{li2026pando}. Two caveats matter when citing PANDO here: its backbone stack is frontier-scale closed models, so its absolute success rates are not comparable to the open 4B-class models studied in this thesis; and its ablation attributes most of the success-rate gain to skills rather than routing (routing, compression and caching together contribute about +1.7pp while cutting tokens), so it supports "routing lowers marginal cost" rather than "routing raises success". ReVision routes the *visual token budget*: a learned mask drops temporally redundant screenshot patches and the backbone is fine-tuned on filtered trajectories, cutting roughly 46% of visual tokens with a small success gain \citep{abaskohi2026revision}. Avenir-Web routes across a mixture of grounding *experts* for multimodal web agents \citep{li2026avenirweb}. One level down the stack, ModServe characterises multimodal *serving* and shows image-heavy requests stress prefill and time-to-first-token differently from text-only ones, motivating modality-aware resource disaggregation \citep{qiu2025modserve}.

### 2.3.3 The missing axis: representation-level routing

Surveying the arms above — model identity, model capacity, numeric precision, visual token budget, grounding expert, serving pathway — a pattern is visible: every system varies *how much computation* processes the input, while the input representation itself stays fixed. The complementary axis, *representation-level routing within a single model*, is unfilled: selecting per task between different textual renderings of the same browser state.

This axis is well-defined because the candidate representations are closely matched in content without being information-identical. In the environments studied here, the DOM/AXTree view and the `[SOM_MARKS]` view are generated from the same accessibility-tree pass and are matched on the *element inventory* — every interactive node, its role, and its label appear in both, at near-identical character length (verified empirically in the experimental chapters). What the flat indexed list gives up is structure: nesting, sibling order, and containment relations are themselves information, and the two views additionally differ in identifier contract (native accessibility-tree node ids versus sequential 1..K selection ids, the standard SoM convention). That structural difference is precisely the routed variable. This also sharpens the contrast with §2.3.2: pruning systems change the representation too, but they do so by *removing* content to save cost, whereas the arms studied here hold the element inventory fixed and vary only its structural rendering — token-neutral reformatting rather than information removal.

It also distinguishes the proposal from ordinary prompt selection. A representation arm is not a different instruction template wrapped around the same observation; it changes the observation object that enters the agent loop at every step, and thereby (as Chapter 4 shows) the trajectory the agent follows. The deployment logic mirrors model cascades: try the cheap representation, monitor a routing signal, escalate only when the cheap view appears misaligned with the task — except that here even the "expensive" arm can avoid image tokens entirely.

## 2.4 Prompt-format sensitivity: why representation is a causal variable

The plausibility of representation routing rests on a broader, well-replicated fact: semantically equivalent prompts induce different model behaviour when surface form changes. Sclar et al. quantify sensitivity to "spurious" prompt-format features — separators, casing, ordering — and find accuracy swings large enough to reorder model rankings, with no change in task semantics \citep{sclar2024promptformat}. Mishra et al. show the constructive counterpart: reframing instructions into forms better aligned with a model's training distribution improves few-shot performance \citep{mishra2022reframing}. For web agents the implication is direct. An AXTree serialisation and a `[SOM_MARKS]` list of the same page differ exactly in the features this literature flags: punctuation, indentation, repeated role tokens, ID patterns, local token neighbourhoods. Treating them as "the same information" is a category error; they are different stimuli that condition different action distributions, step after step, compounding over a trajectory in a way single-shot benchmarks never exercise.

Recent mechanistic work sharpens this from correlation toward mechanism. Judge Circuits applies causal edge-attribution patching to LLM-as-judge models across the same backbone families used in this thesis (Qwen2.5, Gemma-3, Llama-3) and localises a sparse "latent evaluator" in mid-to-late MLP layers, whose continuous judgment signal is read out through *fragile, format-specific terminal branches* \citep{feldhus2026judgecircuits}. Two caveats bound the transfer, and this thesis states both rather than over-claiming. First, there is a domain gap: the "format" manipulated there is the judge's *output* format, not an agent's *input* observation, so the connection is conceptual — evidence that format-conditional computation is mechanistically real and separable from content — not direct evidence about web agents. Second, their most actionable finding is that this separability is family- and scale-dependent: modular in Gemma-3-27B but *entangled* in the smaller Gemma-3-12B, where ablating the format circuitry collapses unrelated knowledge. The cross-family baseline in this thesis (Gemma-3-4B) is smaller still, so format/content separability may be weaker for it than for the Qwen baselines — registered in advance as a predicted confound for the cross-family results, not discovered post hoc. If separability does fail at this scale, the cross-family arm functions as a test of routing under entanglement rather than as a clean replication — an outcome the per-cell stratification of the experimental design is built to surface rather than average away.

This thesis deliberately stops at the behavioural level: mechanism-level analysis (activation patching, layer probes) is out of scope for this thesis, and no mechanistic claim is made about *why* the formats behave differently. The literature above is used only to establish that format effects are expected, real, and worth measuring — not as a substitute for the measurements.

## 2.5 Confidence signals for routing decisions

A router needs a per-task (or per-step) signal predicting whether the cheap arm will suffice. The signals available without extra model calls — "intrinsic" signals — derive mostly from the model's own token distribution, and a substantial uncertainty-quantification literature warns against using them raw. The canonical result is Guo et al.: modern neural networks are systematically miscalibrated, and a single post-hoc temperature parameter substantially repairs calibration \citep{guo2017calibration}. For language models specifically, Kadavath et al. show that self-evaluation quantities (the probability a model assigns to its own answer being true) are usefully calibrated *at scale*, with calibration degrading for smaller models — a directly relevant caveat when the routed model is a 4B-parameter VLM \citep{kadavath2022know}. Kuhn et al. refine token-level uncertainty into *semantic* entropy, computing uncertainty over meaning-equivalence classes rather than surface strings, because token-level entropy conflates lexical variety with genuine uncertainty \citep{kuhn2023semantic}.

Three practical warnings follow from these anchors when the routed model is small. Miscalibration should be assumed by default rather than discovered late \citep{guo2017calibration}; whatever reliability self-assessment enjoys at frontier scale cannot be presumed at 4B, since it improves with scale \citep{kadavath2022know}; and token-level scores conflate surface variety with genuine uncertainty, so response length and verbosity act as nuisance variables on any averaged log-probability signal \citep{kuhn2023semantic}. Beyond these, an internal survey of routing signals for web-navigation agents (spanning behavioural, external-verification, and intrinsic signal families) collected further reported failure modes — overconfidence under distribution shift, non-propagation of single-step confidence through multi-step trajectories, and strong sensitivity of routing quality to threshold selection — which this thesis treats as candidate failure modes to verify empirically rather than as established results (a citation pass to the underlying published studies is scheduled before the final version). Most importantly, we are not aware — as of June 2026 — of a published systematic comparison of routing-signal quality *across observation-representation modes* for small VLMs on WebArena-style benchmarks, the regime of interest here. The experimental design therefore treats signal quality as something to be measured, not assumed: every condition logs a per-task confidence summary (mean/min token log-probability and decision margins), success-signal AUROC is reported per mode, and the learned router (Chapter 6) is trained and evaluated with site-stratified cross-validation rather than a fixed threshold.

A final, less obvious constraint comes from the serving layer: for API-served models, nondeterminism in batched inference means the same input can yield different outputs across calls \citep{he2025nondeterminism}, injecting noise into any confidence signal computed from logged probabilities. Section 2.7 returns to this as a measurement problem; for routing it implies signal distributions should be treated as noisy in deployment, another reason to prefer learned calibration over fixed thresholds.

## 2.6 Cost-efficient inference for web agents

Web-agent efficiency work has mostly meant *pruning or scheduling* expensive context. On the text side, AXTree observations are long and noisy; FocusAgent uses a lightweight retriever to trim AXTree lines before the main agent sees them, reducing context while preserving the hierarchical representation \citep{kerboua2025focusagent}. On the image side, the costs are prompt-processing time, memory pressure, and time-to-first-token \citep{qiu2025modserve}; ReVision attacks the same budget by learning which screenshot patches are temporally redundant, at the price of fine-tuning the backbone \citep{abaskohi2026revision}.

The phantom configurations studied in this thesis represent a third strategy that the efficiency literature does not contain: *text reformatting*. Nothing is pruned and nothing is scheduled; the `[SOM_MARKS]` list is generated from the same accessibility metadata already computed for the page, sent *without* the marked screenshot, eliminating image-token cost entirely while preserving a discrete element index. Its textual length is comparable to the AXTree it replaces; the change is structural, not quantitative. This matters because most cost reductions trade information away — smaller models, shorter contexts, lower image resolution, fewer retrieved lines — and their evaluation question is "how much quality survives the cut?". A reformatting arm poses a different question: can a near-free re-arrangement of already-available text *change which tasks succeed*? If the cheap arm's success pool merely shrinks relative to richer modes, it is a degraded fallback; if it is partially *disjoint* — succeeding on tasks the richer modes miss — then it has positive option value in a routing menu even at equal average success. That distinction, between compression and complementarity, is why the experimental chapters report per-task overlap structure and drop-one oracle value rather than average success alone, and it is invisible in the headline-number methodology of §2.1.

## 2.7 Evaluation reliability, nondeterminism, and reproducibility

Any claim of the form "representation X succeeds where Y fails, by Δpp" is only as good as the evaluator and the run-to-run stability behind it. Two recent literatures bear directly on this, and both shaped the experimental protocol of this thesis.

**Evaluator validity.** Xue et al.'s "An Illusion of Progress?" crystallised growing doubt about how web-agent success is measured \citep{xue2025illusion}, and AgentRewardBench benchmarks LLM judges of agent trajectories directly \citep{lu2025agentrewardbench}; WebCanvas extends evaluation to the live web with critical intermediate action/state criteria \citep{pan2024webcanvas}. A recent wave (late 2025–2026) of *verifiable-environment synthesis* responds by building environments whose judges are deterministic by construction — and in doing so, measured how unreliable judging actually is. WebGym scales to 127k real sites but pays with a GPT-4o rubric judge: human validation (n=80) showed improving precision (~73→93%) cost recall (~96→85%), with residual error "almost impossible to eliminate" \citep{bai2026webgym}. InfiniteWeb synthesises static sites with purpose-built deterministic JavaScript evaluators — which still show ~5% error under human audit \citep{zhang2026infiniteweb}. AutoWebWorld generates finite-state-machine-backed sites with deterministic goal predicates, yet its "infinite" generation deduplicates to 1,215 distinct trajectories, and its own external comparisons fall back to an LLM judge \citep{wu2026autowebworld}. MobileGym, the mobile-domain analogue, measures a 10.2% VLM-judge error rate (12/118 audited trajectories) and replaces free-text answer matching with typed form matchers precisely because string matching produces both false rejects (paraphrases) and false accepts (chain-of-thought leaking the gold answer) \citep{wu2026mobilegym}. OpenApps adds an orthogonal reliability axis: under controlled environment *variations*, fixed-app success-rate variance understates deployment variance by more than 2×, and failure reporting in the field typically rests on "anecdotal evidence alone" \citep{ullrich2025openapps}. The collective lesson is sobering: even purpose-built deterministic evaluators err at the percent level, LLM judges err at the ten-percent level, and the community's response has been to *synthesise new environments* rather than audit the evaluators of existing ones. This thesis takes the complementary path for its measurement substrate: it keeps the established VWA evaluator (so results remain comparable to the literature) but treats evaluator failure as a live hypothesis — auditing false positives encountered during failure analysis, maintaining a catalogued taxonomy of scaffold, agent, and benchmark-evaluator failure classes, and reporting scored-task counts after documented exclusions.

**Run-to-run stability.** A second threat is that the *agent* is not a deterministic function of its input. For API-served models, batched inference can make outputs depend on co-scheduled traffic \citep{he2025nondeterminism}, and numeric precision alone can flip greedy decoding paths \citep{yuan2025numerical}. This is not hypothetical in this project: replicate runs of the largest baseline through its commercial API — launched from byte-identical initial inputs, with divergence then compounding across the trajectory — showed per-task success flips on the order of ten percentage points while net success rates moved only ~1pp, a noise floor that any per-task complementarity claim must clear. The protocol therefore distinguishes claims by their exposure: aggregate success-rate comparisons (robust to per-task churn) are gated by pooled tests across site×model cells, while per-task structures (overlap pools, oracle values) carry measured-noise caveats, and the locally-served baselines — bitwise deterministic in our setup given greedy decoding and a fixed hardware/kernel configuration, a determinism that does not survive hardware changes — anchor the cross-model story. Following OpenApps' variance finding, claims are worded as holding *within this environment instantiation*, and the per-(site, model) stratification of the statistical design is itself a hedge against cross-cell heterogeneity \citep{ullrich2025openapps}.

These two literatures also motivate the heavier process machinery documented in the methods chapter — preregistered hypotheses and gates with witnessed amendments, manifest-bound runs, per-condition environment resets, and single-baseline-per-site scheduling — which exists, in short, because the reviewed evidence says both the judge and the subject are noisier than the field's reporting conventions assume.

## 2.8 Position of this work

This thesis sits at the intersection of four literatures that do not currently speak to each other. From §2.2: Set-of-Marks and its descendants treat marks text as an auxiliary index bound to the marked image \citep{yang2023som,yang2025magma,li2025ferretui2}, and benchmarks compare DOM, SoM, and Vision as fixed configurations \citep{zhou2024webarena,koh2024visualwebarena,zheng2024seeact} — neither isolates the marks-text-without-image configuration as a controlled axis. From §2.3: routing systems optimise over models, capacities, precisions, token budgets, and experts, but not over textual renderings of the same browser state \citep{chen2023frugalgpt,ong2025routellm,li2026dmr,li2026pando,abaskohi2026revision}. From §2.4: format-sensitivity work predicts exactly such effects but has not measured task-pool complementarity in interactive, multi-step settings \citep{sclar2024promptformat,feldhus2026judgecircuits}. From §2.5–§2.7: routing-signal and evaluation-reliability work supplies the measurement discipline, but has not been applied to a representation-routing question.

The gap is therefore a *characterisation* gap, not a first-deployment gap, and the thesis is explicit about this: production systems have long dropped images for cost reasons, and artifact precedents for marked observations and textual references are acknowledged rather than contested. To our knowledge — as of June 2026 — what is missing from the literature is the controlled science: the `[SOM_MARKS]` text isolated from its screenshot; crossed with prompt family in a 2×2 so that text-payload effects separate from prompt-style effects; compared against DOM, SoM, and Vision on identical task pools across two sites and three models (including a cross-family control); scored not only by average success but by overlap structure, drop-one oracle value, cost, latency, and routing-signal quality; and reported against a measured run-to-run noise floor under a preregistered analysis plan. The scope of the resulting claims is correspondingly bounded: they concern textual-flattening-versus-hierarchy routing for AXTree-style observations in SoM-scaffolded multimodal web agents, within this environment instantiation — not representation routing for arbitrary LLM systems.

Chapter 3 formalises the phantom routing space and the experimental design; Chapter 4 presents the controlled evidence; Chapter 5 analyses failure structure across modes; Chapter 6 builds and evaluates the cost-aware router on top of the measured space.
