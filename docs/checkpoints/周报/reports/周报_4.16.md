## 1. B1 Classifieds 三模式完整结果

三模式全部完成（各 234 tasks），核心数字：

|           | DOM       | SoM        | Vision     |
|-----------|-----------|------------|------------|
| Raw SR    | 8.97% (21/234) | **20.51%** (48/234) | 12.39% (29/234) |
| Adjusted SR | **0.85%** (2/234) | **16.24%** (38/234) | **8.12%** (19/234) |
| 平均成本/ep | $0.074   | $0.077     | **$0.029** |

- SoM vs DOM：McNemar p=7.4e-6（显著）
- SoM vs Vision：McNemar p=0.0013（显著）
- Vision vs DOM：McNemar p=0.0002（显著，adjusted 后 19 vs 2）
- Vision 成本仅 DOM 的 39%，Wilcoxon p<1e-25

**注意**：B1 Classifieds 数据采集时 DOM 模式存在参考图三重 bug（§33 传递阻断 + §34 编码失效 + §36 标签无意义），DOM 模式实际完全无法利用参考图。该问题已在后续 Reddit/Shopping run 中修复，Classifieds 的 DOM SR 可能因此偏低。

Raw 与 Adjusted 之间的巨大落差来自两类假阳性，这是本周最重要的方法论发现。

### 1.1 Visual False Positive（§20）

DOM 模式无图，但 21 个"成功"中 **19 个是视觉任务碰巧得分**（例如"找蓝色皮划艇"——DOM 看不到颜色，但搜索结果恰好第一个就是目标商品）。检测方法：交叉标注任务是否依赖视觉信息（关键词匹配 + 评测类型），DOM 模式成功的视觉任务即为假阳性。

Classifieds 站 67% 的任务是视觉任务（162/234），这意味着 DOM 的 raw SR 被严重膨胀。**Adjusted 后 DOM 真实 SR 仅 0.85%（2/234）**——纯文本表征在视觉密集站点几乎无用。

B0（235B）情况更复杂（§56）：35 个成功中 7 个 na_fp + 10 个 visual_fp + 17 个属于新发现的盲区类型（需任务级人工核验）+ 1 个真实成功。Adjusted SR 7.7%（现行标准）~0.4%（严格标准），但大模型展现了 4B 不具备的能力（翻页、价格筛选、tab_focus），FP 体系需要更细粒度的分类。

### 1.2 N/A Task ua_match 假阳性（§27）

VWA 有 10 个 N/A reference task（标注为"不可行"的任务），`ua_match` 评测器用 GPT-4o-mini 判断 agent 回答是否与 reference 语义一致。发现 **10 个全部误判为成功**：

- **Type A**：agent 空 answer（被 max_steps 截断，runner 自动提交空字符串）→ GPT-4o-mini 判为"隐式承认 N/A"→ score=1.0
- **Type B**：agent 提交了错误答案 → prompt 中 "even if implicitly" 过于宽松 → 仍判 "same"

双重根因：(1) ua_match prompt 把 agent 答案标为 "reported unachievable reason"，预设 agent 在回答 N/A；(2) agent prompt 的 Rule 4 说 "NEVER give up"，无 N/A 提交出口，必然循环到被截断。DOM 10/10、SoM 已完成的 4/4 全部 FP——误判与观测模式无关。这 10 个 N/A task 全部是 visual task，已被 Visual FP 过滤覆盖，不额外影响 adjusted SR。

### 1.3 Oracle Routing Ceiling

跨模式 Oracle（每个 task 取最优模式结果）：

- Oracle ceiling (adjusted): **19.66%**，在 SoM 16.24% 之上 headroom **3.42pp**
- Oracle 选择分布：SoM ~25 / Vision ~19 / DOM 2
- **Vision-only 成功 7 个**（全是纯视觉任务，SoM/DOM 均失败）
- **DOM+Vision 交集=0**（完全互补）
- SoM+Vision（非 DOM）= 12 个

结论：**SoM ↔ Vision 路由**是主要方向（headroom 3.42pp）；DOM 不纳入路由（adjusted SR 0.85%，独占成功仅 1 个）。

## 2. 关键行为发现

### 2.1 DOM vs SoM 差距根因：Mirage Effect（§18/§23）

初始假设是"SoM 文本更紧凑，DOM AXTree 过长导致信息淹没"。§23 修正：**Mirage Effect 才是主因**。

Mirage 论文（Asadi et al., arXiv:2603.21687, Stanford 2026-04）发现 VLM 无图时仍自信描述视觉特征，无图准确率达有图的 70-80%。B1 实验观察高度吻合：

| Mirage 论文 | B1 观察 |
|---|---|
| 无图准确率 70-80% 有图 | DOM 90.5% "成功"是 visual lucky hits |
| Mirage-mode > Guess-mode | SoM 降级场景（标注失败无图）成功率反而提升 |
| 消息格式触发推理路径切换 | SoM prompt 暗示截图存在 → 激活隐藏的文本-视觉关联 |

**解释力**：DOM 和 SoM 拿到的文本信息量差异不大（SoM marks 扁平列表 vs AXTree 层级树），但 SoM prompt 提及 screenshot 的存在就足以触发质变的推理路径。这不是"看图更好"，而是"被告知有图就更好"。

### 2.2 认知-执行鸿沟（§31）

Case study（task 58：找 City 过滤后最旧商品）：

- **DOM/SoM** thought 多次提到翻页意图（"I should go to the next page"）和 City 过滤意图（"I need to filter by city"），但**无法执行**——不知道该点哪个元素、不知道翻页控件在哪
- **Vision** 成功执行：直接看到分页按钮的视觉位置，点击翻页到第 3 页完成任务

这说明 DOM/SoM 模式的失败不总是"不知道该做什么"（认知），而是"知道该做什么但做不出来"（执行）。图片提供的空间信息弥合了这一鸿沟。

更广泛地：agent 极少翻页（DOM 从未翻页，SoM/Vision 偶有），极少 scroll up（DOM 3.7%，SoM 11.2%），从不使用 Sort By。视觉信息使分页控件更显著（SoM scroll up 3× DOM），但能力未泛化为稳定策略。

### 2.3 零自纠正能力（§32）

Vision task 分析发现系统性坐标偏移（Art+crafts 类目 → Books 类目 misclick），且 agent 在 misclick 后以**完全相同的坐标和 confidence** 重复点击，不会微调。这意味着 auto-scroll/retry 类模块对 Vision 模式 SR 影响为零——没有"重试机会"可抢。

## 3. 路由理论框架

### 3.1 信号评估（Preliminary，基于非最终数据）

| 信号类型 | 具体信号 | AUROC | 结论 |
|---------|---------|-------|------|
| Token-level | mean/min logprob, margin, entropy（6 指标） | **0.497** | 接近随机，4B 过度自信，Phase 2 不采用 |
| Behavioral | action diversity（unique action 下降率） | **0.74** | 跨模式一致，最强免费信号 |
| Behavioral | page_unchanged_streak, URL 重访 | 已实现 | R2D2 文献：50% 错误减少 |
| Verbalized | prompt 中 `confidence: 0.0-1.0` 自报 | **0.69** | SoM+Vision 可用，与行为信号正交（ρ 低） |

Token-level 信号失效有充分文献支撑：8 篇调研（§15）一致指出 raw logprob 在小 VLM 上过度自信，校准前不可靠。**最实际路线：免费行为信号触发模式升级**（现有循环/停滞检测只需从"触发 retry"改为"触发模式切换"）。

### 3.2 Routing Signal 文献综述（§24）

~1400 篇文献系统综述（2023-2026），建立优先级：

| 信号 | 状态 | 文献支撑 |
|------|------|---------|
| page_unchanged_streak / no_progress_streak | 已实现 | `state_change.py` |
| URL 重访检测 | 已加入分析 | R2D2（50% 错误减少） |
| Action diversity | 已加入分析 | WebGym, TGPO（AUROC=0.74） |
| PRM verifier（7B） | 不采用 | WebArbiter +9.1pp，但 4B actor 旁跑 7B 不经济 |
| Learned router | 不采用 | FrugalGPT 98% 成本削减，但需训练数据 |

### 3.3 Phantom-SoM 消融设计（§25）

Mirage Effect 如果成立，则存在一个零成本中间层：**Phantom-SoM**（SoM prompt + SoM marks 文本，但不附带图片）。理论上它能获得大部分 SoM 增益（因为增益来自 prompt 格式而非图片本身），成本与 DOM 相当。

为严格验证，设计 5 组消融实验分解三层混淆变量（prompt/scaffold、文本格式、图片暗示）：

| 组 | Prompt | 文本 | 图 | 隔离变量 |
|---|---|---|---|---|
| A: DOM | DOM | AXTree | 无 | 基准（复用 B1） |
| B: Phantom-SoM | SoM | SoM marks | **无** | ①+②+③ 混合 |
| C: Full SoM | SoM | SoM marks | 有 | 纯图片（复用 B1） |
| D: DOM-text+SoM-prompt | SoM | AXTree | 无 | 纯 ① prompt |
| E: SoM-text+DOM-prompt | DOM | SoM marks | 无 | 纯 ② 格式 |

因果分解：`D-A`=prompt 效应，`E-A`=格式效应，`C-B`=图片效应，`B-D-E+A`≈mirage。**D 是关键判别组**：Scaffold Effect 文献（Vu & Balloccu 2026——prompt 仅提及 MRI 可用就解释 70-80% 性能变化）预测 D≈B，即效果全来自 prompt 层。A/C 复用 B1 数据（零额外成本），B+D 各需 234 tasks。

**P79 novelty**：首个 intra-model observation-mode routing 研究 + 系统性四因素消融 + 把 mirage effect 当 routing feature 而非 bug。

## 4. B0 初步观察（Preliminary）

B0（Qwen3-235B-A22B）Classifieds DOM 已跑完初版（受 parse_error 影响，待重跑），初步观察：

- **大模型独有能力**：翻页（B1 从未翻页）、价格筛选（主动使用 filter 控件）、tab_focus（多 Tab 对比任务）——这些是 4B 完全不具备的行为
- **FP 体系更复杂**：35 个成功中只有 1 个"确定真实"成功，其余分为 na_fp(7) / visual_fp(10) / 待核验盲区(17)，需更细粒度的 FP 分类体系
- **Parse_error 20.1%**：Bedrock 不支持 thinking 分离，235B 推理文本与 JSON 混合输出，keyword fallback 误判。已实现 Tool Calling + GLM 提取双重根治方案（§67），等 API 额度到账重跑
- **Scroll 方向混乱**：deltaY 符号约定在 CSS/Win32/macOS 间不一致，235B 训练数据混合三套约定，导致 scroll 方向不可预测。已实现 scroll_direction enum 语义化（§67）

**核心启示**：235B 展现了与 4B 质的不同的能力谱——这验证了 capability-aware routing 的前提假设（最优表征是模型能力的函数，§9）。
