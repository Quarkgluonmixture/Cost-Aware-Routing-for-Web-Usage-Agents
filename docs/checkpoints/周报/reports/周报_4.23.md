## 2. DOM 模式的独特价值

B1 DOM 有 7 个独占成功（SoM 和 Vision 均失败）：4 个通过精确 element_id 点击完成导航，3 个通过文本提取获得正确答案。这类任务依赖准确的元素定位，DOM 的 id 机制比坐标点击（Vision）或带标注截图（SoM）更可靠。

B0 DOM 表现更强（8.48% vs 4.91%，1.73 倍），因为 235B 具备 4B 不具备的行为：主动翻页（33+ task）、使用价格筛选器（21+ task）、多 Tab 切换。**DOM 的价值与模型能力正相关。**

## 3. 失败模式分析

### 3.1 B1 三模式失败分布

| 失败类型 | DOM | SoM | Vision | 特征 |
|---------|-----|-----|--------|------|
| 无进展循环 | 36.8% | 36.8% | **58.1%** | Vision 坐标不准导致反复无效操作 |
| 过早终止 | 6.0% | **12.0%** | 14.1% | SoM 首屏信息密度高，模型未充分探索即给出答案 |
| 答案不匹配 | **10.7%** | 6.4% | 2.1% | DOM 缺少视觉信息，提交的答案偏差较大 |

三种模式的失败路径明显不同，说明它们在不同任务类型上各有优劣，这为路由提供了基础。

### 3.2 B0 vs B1 行为差异

235B 在坐标点击失败后会尝试调整坐标重试，4B 则以完全相同的坐标重复点击。但 235B 存在"过度自信"问题：首屏看到部分匹配结果即给出答案，不继续翻页或滚动。SoM 模式下尤为明显——首屏信息密度最高，配合 235B 的高置信度，最容易过早终止。

## 4. 路由信号评估

AUROC 衡量信号区分成功/失败的能力（0.5 为随机基线），基于 B1 三模式 702 episodes（adjusted labels）：

| 信号 | AUROC | 95% CI | DOM | SoM | Vision |
|------|-------|--------|-----|-----|--------|
| **自报置信度** (verbalized) | **0.769** | [0.704, 0.832] | 0.753 | 0.755 | 0.757 |
| **URL 重访次数** (url_revisit_max) | **0.767** | [0.718, 0.814] | 0.755 | 0.727 | 0.816 |
| **动作多样性** (action_diversity) | **0.749** | [0.688, 0.810] | 0.738 | 0.706 | 0.809 |
| 最长重复动作串 (max_repeat_streak) | 0.673 | [0.607, 0.735] | 0.761 | 0.604 | 0.744 |
| Token 级别（entropy/margin 等） | ≈0.50 | — | — | — | — |

**自报置信度**跨模式最稳定（三模式 AUROC 仅差 0.004），最适合作为跨模式路由的统一判据。**行为信号**（url_revisit、action_diversity）同样有效，且 Vision 模式下区分力最强（0.809-0.816），因为 Vision 失败时的循环行为更明显。**Token 级别信号完全无用**（AUROC ≈ 0.5），4B 模型的概率分布过于集中，无法从 logprob/entropy 中提取有意义的不确定性。

## 5. 路由格局：三模式路由可行

### 5.1 理论上限（Oracle Routing）

| | B0 (235B) | B1 (4B) |
|--|----|----|
| 最优单模式（SoM） | 20.98% | 13.84% |
| Oracle 三模式 | **29.06%** | **18.80%** |
| 提升空间 | +8.55pp | +5.13pp |

B0 的路由空间为 B1 的 1.67 倍。

### 5.2 成功集合互补性（Venn 分析）

**B1 独占成功分布（adjusted）：**

| 集合 | 数量 | 说明 |
|------|------|------|
| 仅 SoM | **19** | 最大独占集，SoM 主力地位 |
| SoM + Vision（非 DOM） | 8 | 视觉信息的共同优势 |
| 仅 DOM | **7** | 精确元素定位的不可替代价值 |
| 仅 Vision | 5 | 低成本替代路径 |
| DOM + SoM（非 Vision） | 3 | — |
| 三模式均成功 | 2 | 简单任务，差异不大 |
| **DOM + Vision（非 SoM）** | **0** | DOM 和 Vision 成功集完全不重叠 |

**B0 独占成功分布（adjusted）：**

| 集合 | 数量 | 说明 |
|------|------|------|
| 仅 SoM | **27** | 仍是最大独占集 |
| 仅 Vision | **15** | 235B 视觉能力更强，Vision 独占大幅增加 |
| 三模式均成功 | 9 | DOM 在这些交集任务上最便宜（$0.013 vs SoM $0.020） |
| DOM + SoM / SoM + Vision | 各 6 | — |
| 仅 DOM | 4 | — |

### 5.3 关键发现

- **DOM 和 Vision 的成功任务完全不重叠**（B1 交集 = 0），天然适合互补路由
- **B0 三模式 Oracle 分布更均衡**：SoM 42.6%、Vision 38.2%、DOM 19.1%；B1 中 SoM 占 68.2%，路由空间较集中
- 上周认为 DOM 无价值仅在 SoM↔Vision 间路由，现修正为**三模式路由**
- **最优模式取决于模型能力**（§9 假设得到验证）：模型越强，各模式均更强，路由空间更大
