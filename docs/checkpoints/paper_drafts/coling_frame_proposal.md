## 0. 一句话

工作标题（Codex 提议，采用）：*Text, Screenshots, or Both? Representation Value and Task Routing in Web Agents*

## 1. 问题与术语

- 问题是部署选择：页面**文本**（DOM / 无障碍树）、页面**截图**（Vision）、还是**融合**（SoM：标注截图 + 标记文本）。四个无截图变体（含 P-SoM）是控制混杂用的消融臂，不是并列选项。
- ⚠️ 「文本模式」是**页面截图不可见**，不是零视觉输入：任务自带的参考图在所有模式里都会注入（§549.2）。全文不写「纯文本」。
- 路由 = task level：开跑前按题决定一次，整题不换（step 级路由不在本文范围）。

## 2. 论证（五步）

**① 没有一个部署选择在所有工作负载上都最好。** SoM / DOM / Vision 的排名随站点与 backbone 翻转；SoM − DOM 在 cls_B0 / B1 为 +9.82 / +8.04pp（区间排除 0），WA 两格为负但跨 0。只讲异质性，不把 8 格当 8 次独立检验（同站不同 backbone 用同一批题）。
证据：`representation_class_comparison`、`fusion_premium`。强度：中等、描述性。

**② 截图有具体、可复现的价值，而且在题类层面能事先知道（正面锚点）。** 用只差一张截图的匹配消融 SoM − P-SoM。一条 0 token 的意图正则在 classifieds 上事先圈出 71 题：
- B0：命中题 +25.35pp（21/3），**同条件重跑 +26.76pp（23/4）**；
- B1 +11.27pp，GPT-5.6 +29.58pp；集中度随能力增强（B2 → B1 → B0 → B5）；
- reddit 不成立；shopping 命中题每臂只有 0–5 个成功，测不出；WA 只命中 5 题，测不了。

证据：`visual_intent_routing`（§548）· §549.2。强度：classifieds 上较强（含重跑复现），**不是跨站点的一般规律**。B5 带预算记账限定（§508.1）。

**③ 按题的表征偏好是真的，但单次 run 测不准。** 无交互零模型（条件于题难度与臂易度，curveball 精确抽样），三个全复测格 Holm 全过：
- 三选一下单次信度 0.31–0.50，每题要 2–3 次重跑（§550）；
- 六臂下单次信度 0.14–0.46，每题要 2–6 次重跑（§543）。

佐证：同一道题，一次 run 的偏好搬到重跑上，比前沿多 +2.4~+10.5pp（§546）；全复测格的 2^6 种 run 组合里，SoM 最少仍有 6 / 4 / 1 个唯一解。
强度：三格、模型条件下的探索性证据；信度不是任何学习器的性能上界。

**④ 只用训练数据定下来的路由器兑现不了这份价值。** 比较对象是固定臂及其随机混合构成的前沿，不只是「谁支配谁」。
- **三选一**（§550）：triage 曲线合并后在低预算端高出前沿 +1.69pp（p 0.001）。这是**难度**杠杆：判为没希望的题送最便宜的臂。但工作点只用训练数据选时，合并 triage +0.59 [−1.53, 1.23]、选臂器 +0.23，都不显著。
- **六选一**（§539 / §544）：可部署六头合并显著低于前沿（95% 上界 −0.14pp）。
- 模板隔离、换 run 评估（§546，已修泄漏）、三种成本口径（§545）、B5 与 shopping（§547）：都没有兑现。

强度：支持「所测特征 + 学习器在这些数据上没有兑现」，**不支持「收益不存在」或「任何估计器都学不到」**。

**⑤ 方法收束（可迁移）。** 报多臂 agent 结果时：
- 附逐臂、逐格的重跑结果，不报一个统一的翻转率或分辨率门槛；
- 用匹配消融隔离截图价值；
- 用 D-study 定每题要跑几次才能拿到可训练的标签；
- 拿可部署策略（只在训练数据上定工作点）对固定臂 + 随机混合的前沿比，不拿事后 oracle 当可兑现收益。

预算 / 难度这一半可学，但属于已有的 early-abort 家族（§535），前瞻检验只在 P-prompt 上可识别地通过（§542），放讨论不当贡献。

## 5. 审稿风险与预先处理

1. **「你证明了表征有用，没证明路由有用。」** 直接接受，这正是论文的分离式贡献；正面（②）与未兑现（④）都在正文。
2. **「负结果只是学习器太弱。」** 结论限定到所测特征、学习器和数据；报 LLM / bandit / lookahead pilot 及其限制；不写「估计器无关」。
3. **「问三选一，答六选一。」** 已补三臂（§550），正文用三臂，六臂进附录。
4. **「正面结果只在一个站点。」** 正文就写成站点依赖：classifieds 成立且重跑复现，reddit 不成立，其余测不了。
5. **「事后选择、多重比较。」** 标探索性；列出检验族；区分曲线最大值（看过测试结果）与可部署工作点。
6. **「harness / 站点漂移在作祟。」** 方法节列出无效单元与筛选规则；shopping clean 与全量并列。
7. **「成本没有部署意义。」** API 账单、本地 GPU 时间、墙钟分开；每次尝试与每次成功分开（B5：SoM 每次成功 $0.451 vs DOM $0.581，区间重叠）。
