# NAACL 2027 main conference — 下一个目标

学长 2026-08-08 定的下一站。**在毕设 (09-01) 之后**启动，不与之抢时间。

## 为什么这条路是通的

REALM 提交时 Cross Submission 勾了 `Plan to submit to ACL ARR 2026 August`，且投的是
**`Non-archival long`** —— **主会投稿权当时就是特意保住的**（见 `task_realm_paper_b_router_negative`）。
所以 REALM 这条线不构成 double submission 障碍，这是 07-28 合并拍板时就铺好的路。

## 启动前必须先查、不要凭记忆

- **ACL ARR 的哪个 cycle 喂 NAACL 2027**，以及该 cycle 的 submission / review / commitment 日期
  → 查官方日历，**不要用记忆里的日期**（ARR 周期年年调，记错一轮就废一个 cycle）
- NAACL 2027 的 archival 政策与页数限制
- REALM 非归档轨与 ARR 提交的具体衔接手续

## 输入

1. **REALM 审稿意见（notif 2026-09-07）** — 免费的一轮 top-tier 反馈，正好落在毕设交付之后。
   这是决定「按原框架投还是重构」的主要依据，**等它到手再定稿件形态**。
2. **REALM 稿本体**（Submission #192，正文 8 页）+ 其四步论证结构
3. **毕设全稿**（09-01）— 毕设为了 rubric 补的文献图谱 / benchmark EDA / 形式化公式，
   有一部分可反哺会议稿的 appendix

## 与毕设的关系

**不是同一份东西**。毕设 = problem-first、concept-first、文献综述与 EDA 齐备的长文；
NAACL 稿 = 8-9 页、单一论证线。共享数据与图，不共享结构。
先交毕设，再以 REALM 审稿意见为输入重整会议稿。
