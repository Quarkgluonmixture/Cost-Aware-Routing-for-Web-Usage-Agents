# Domain-term whitelist: the single source of truth for terms that must
# survive any rewrite untouched (no synonym substitution, no expansion of
# dash compounds, no "simplification").
#
# Consumed by:
#   - .claude/skills/deslop-paper/SKILL.md  (rewrite layer, hard constraint)
#   - scripts/invariant_check.py            (occurrence counts must not drift)
#   - scripts/gen_vale_vocab.py             (Vale vocabulary exceptions)
#
# Test for adding a word here: if it were replaced by an everyday synonym,
# would the paper lose a distinguishable, citable, operationalized concept?
#
# One term per line; lines starting with # are comments. Matching (see
# term_pattern in scripts/invariant_check.py):
#   - spaces and hyphens are interchangeable and wrap-safe, so
#     "drop-one oracle" also matches "drop one oracle" and
#     the same phrase broken across two source lines;
#   - word-bounded, so short acronyms are safe to list: DOM does not match
#     "random"/"domain"/"dominant", SoM does not match "some";
#   - regular plurals and possessives count as the same term (DOMs, DOM's);
#     irregular plurals do not (list "policy" and "policies" separately if
#     both matter);
#   - a word with a capital anywhere but the first letter (DOM, SoM, AXTree)
#     is matched case-sensitively, so listing "US" does not count every
#     "us"; ordinary words are case-insensitive.
#
