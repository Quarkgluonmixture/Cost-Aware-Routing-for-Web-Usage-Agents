\section{Per-task preferences are reproducible, but one run measures them poorly}\label{sec:preference}

\S\ref{sec:screenshot} found structure at the level of task \emph{types}. Routing per task needs more. An individual task must prefer one representation over another beyond what an additive model of task difficulty predicts, and the preference must be stable enough to learn from.

\paragraph{A null without task-by-mode structure.} In the three cells where every mode was run twice, let $Y_{imr}\in\{0,1\}$ be the outcome of task $i$ under mode $m$ in run $r$. Under
\[
  \operatorname{logit}\Pr(Y_{imr}=1) = a_i + b_{mr},
\]
every task has its own difficulty and every (mode, run) column its own easiness, but there is no persistent task-by-mode interaction. This is the Rasch model, a special case of the multidimensional item-response models that item-response routers fit \citep{song2025irtrouter}. Here it is the null, and we test for structure beyond it. The row and column sums are sufficient for this model, so, given them, every 0/1 matrix with those sums is equally likely. We approximate this conditional null by curveball Markov-chain sampling \citep{strona2014curveball}, fitting nothing. The statistic is the run-to-run covariance of each task's mode profile, the reproducible part of the interaction: $\hat\sigma^2_{\text{int}} = (\mathrm{MS}_{\text{int}} - \mathrm{MS}_{\text{err}})/2$ from the two-way task $\times$ mode ANOVA with two runs.

\paragraph{Result.} Over the three deployment modes the interaction exceeds the null in all three cells (classifieds B0 $\hat\sigma^2_{\text{int}}=0.033$ against a null 95th percentile of 0.015; VWA-reddit B0 0.018 against 0.009; WA-reddit B1 0.030 against 0.014; $p\le 0.002$ each, Holm across cells). % routing_three_arm null_cells
Over all six modes the same holds (Appendix~\ref{app:sixarm}). Preferences between representations are therefore a reproducible property of tasks that an additive difficulty model does not capture. The test does not say what the extra structure is. A task-specific preference would reject this null, but so would a mode whose success responds more steeply to difficulty than another's. Only the first is a representation preference in the narrow sense.
The preferences also mostly persist where they can be observed directly. Over all six modes, we pick for each task the cheapest mode that succeeded on one run and score it on the rerun. On VWA-reddit B0 and WA-reddit B1, this choice beats the frontier of the fixed modes and their random mixtures (\S\ref{sec:routing}) by 2.4--10.5 points. On VWA-classifieds B0 it lands $+3.57$ or $-0.56$ points relative to the frontier, depending on which run supplies the choice. % routing_crossrun_template_validation diagnostic
That choice uses the task's own label, which no deployment has, so it measures persistence, not an attainable policy.

\paragraph{But a single run measures them poorly.} As in a generalisability decision study \citep{brennan2001generalizability}, the same ANOVA gives the reliability of a task's mode profile averaged over $k$ runs (Figure~\ref{fig:dstudy}). From one run it is 0.34, 0.31 and 0.50 in the three cells; the projection crosses 0.5 at two to three runs (bootstrap ranges 2--4, 2--7 and 1--3). Over six modes it is lower still, 0.14--0.46, with up to six runs projected. This is the reliability of the interaction profile, not of the mode a router picks. It therefore bounds how noisy single-run training labels are, but does not predict when a router starts to win. % routing_three_arm, task_mode_interaction_null

\paragraph{Labels flip most where the choice can change success.} A representation choice can change a run's success only on tasks that some modes solve and others do not; on the other tasks it can change only the cost. Over all six modes, the tasks split this way on the first run are 24--39\% of each of the three fully rerun cells, but 78--84\% of the tasks whose outcome changes in some mode on the rerun. Of the split tasks, 74--86\% change, against 6.5--10.3\% of the rest. % label_instability strata/by_cell: arms-DISAGREE share_of_cell, share_of_all_flips, flip_rate_pct; COMPLEMENT flip_rate_pct
This concentration needs no task-by-mode structure. A binary outcome varies most at intermediate difficulty, and the same no-interaction null over six modes concentrates the changes on these tasks as strongly. The observed ratio of the two change rates, 7.9--11.4, lies between the null's 5th and 95th percentiles in every cell. Still, these tasks show some task-by-mode structure: they change less often than under the null, below its 5th percentile in every cell. % task_mode_interaction_null cells[].null.enrichment, cells[].null.contested_flip_rate

The routing target thus exists. But single-run training labels measure it with a reliability of only 0.31--0.50, and they flip most where the choice can change success. In this sense, routing is least learnable where it is most valuable. This compares tasks within a cell, not cells or backbones, and concerns the labels any router learns from; we do not claim that it alone explains the results of \S\ref{sec:routing}.
