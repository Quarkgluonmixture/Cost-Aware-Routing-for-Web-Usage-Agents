# UCL MSc AISD Final Project / Dissertation 提交规定核验
**Programme:** MSc Artificial Intelligence for Sustainable Development (AISD)  
**Institution:** University College London (UCL)  
**Target academic year:** 2025/26  
**Planned dissertation submission date:** 2026-09-01  
**Research date:** 2026-08-10  

---

## 1. 核验目标

本文档用于核实 UCL MSc **Artificial Intelligence for Sustainable Development (AISD)** 学位中 final project / dissertation 的硬性提交规定，重点包括：

1. 正文长度上限；
2. figures / tables 是否计入长度；
3. appendices 是否计入长度，以及是否有数量或长度限制；
4. references / bibliography 是否计入长度；
5. 是否存在强制 LaTeX / Word 模板，以及字体、字号、行距、页边距等排版要求；
6. 是否要求声明 word count；
7. 生成式 AI 使用声明（GenAI declaration / acknowledgement）的要求；
8. 是否指定引用格式；
9. AISD final project / dissertation 的正确模块代码，尤其核实 `COMP0190` 与 `COMP0191` 的关系。

---

## 2. 证据等级定义

本文档只使用以下四种证据等级：

- **A 官方明文-年度明确**  
  `ucl.ac.uk` 官方来源，且文档明确标注适用于 **2025/26** 或当前目标学年。

- **B 官方明文-年度不明**  
  `ucl.ac.uk` 官方来源，但页面没有明确标出适用学年。

- **C 官方但间接**  
  UCL Academic Manual 或其他 UCL 通用规定，但不是 AISD / COMP0191 项目专属规定。

- **D 第三方或推断**  
  第三方来源，或根据不同年份 / 当前 catalogue / 课程结构所作的推断。

> 原则：如果某一项没有找到 AISD / COMP0191 在 2025/26 学年的公开项目专属规定，则不使用其他 MSc 项目、其他院系、往年规则或一般经验进行填补。

# 5. 关于字数 / 页数限制：目前能确定什么

UCL 2025/26 Academic Manual 没有规定一个统一适用于所有 MSc dissertation 的字数或页数。

相反，它的规则是：

- assessment 可以规定 minimum / maximum word count；
- 若规定 word count，则必须告诉学生如何计算；
- 应明确说明哪些内容 included / excluded；
- 这些具体要求由 module / assessment instructions 给出。

因此目前**不能合法从 UCL 通用规则推出任何 COMP0191 的具体数字**。

下面这些说法在没有 COMP0191 assessment brief 的情况下都不能视为已核实：

- “UCL MSc dissertation 一般 10,000 words”
- “AISD dissertation 是 12,000 words”
- “上限是 50 pages”
- “references 不计”
- “appendix 不计”
- “figures 和 tables 不计”
- “caption 不计”
- “appendix unlimited”

这些都必须以 COMP0191 2025/26 的具体 assessment documentation 为准。

# 6. Figures、Tables、Appendices、References

UCL Academic Manual 的一个关键点是：

> 如果 assessment 使用 word count，则具体 instructions 应说明哪些元素计入或不计入。

因此以下四类内容都不能凭一般经验推断：

### Figures
需要确认：

- figure 本身是否计入；
- figure caption 是否计入；
- figure 内文字是否计入；
- figure 中的大段实验结果是否存在限制。

### Tables
需要确认：

- table body 是否计入；
- table caption 是否计入；
- table 中的大量文字是否可能被视为规避 word count。

### Appendices
需要确认：

- appendix 是否 excluded；
- appendix 是否有页数或字数上限；
- appendix 是否允许放实验表、额外 figures、代码、prompt、完整结果；
- examiner 是否有义务阅读 appendix。

尤其最后一点非常重要：

> **“允许附录”不等于“阅卷人必须阅读附录”。**

如果论文核心论证依赖 appendix 中的信息，即使 appendix 不计长度，也可能影响论文的可评阅性。

### References / bibliography
需要确认：

- bibliography 是否 excluded；
- in-text citations 是否计入；
- footnotes / endnotes 是否计入。

# 9. GenAI 使用声明

## 9.1 UCL 层面已经确认的原则

UCL 对 assessed work 中使用 generative AI 的基本立场是：

- 是否可以使用 GenAI，以及允许使用到什么程度，由具体 assessment 决定；
- 学生必须首先遵守 department / module / assessment 的具体 instructions；
- 如果使用 GenAI，应进行 acknowledgement；
- acknowledgement 应说明 **how GenAI was used**；
- GenAI 不应被列为 author；
- GenAI 不应像普通 scholarly source 一样被当作标准文献 citation。

官方来源：

https://www.ucl.ac.uk/news/2025/feb/can-you-use-ai-exams-and-assessments

# 10. Citation / Referencing Style

目前公开资料没有找到 COMP0191 / AISD 强制使用：

- Harvard
- APA
- IEEE
- ACM
- Vancouver
- Chicago
- MLA

中的任何一种。

UCL Academic Manual 的通用要求是：

- external sources 必须 appropriately cited and referenced；
- 各 Department 负责向学生说明 discipline-specific referencing conventions；
- 这些信息可能出现在：
  - Student Handbook
  - Moodle
  - equivalent programme / module materials

因此：

> **目前不能说 AISD dissertation “必须 IEEE”或“必须 Harvard”。**

如果 COMP0191 没指定唯一格式，最重要的是：

1. 全文一致；
2. citation 与 bibliography 一一对应；
3. 采用本领域标准且清晰的 scholarly style；
4. 不混用多个 style。

# 12. 当前最稳妥结论

截至 2026-08-10，根据公开 UCL 官方资料，可以较有把握地确定：

### 已基本确定

1. **`COMP0190` 是 Project Preparation，不是最终 dissertation。**
2. **AISD final MSc project / dissertation 对应 `COMP0191`。**
3. `COMP0191` 当前官方 catalogue 显示为 **60-credit final project**，100% assessed through dissertation / extended project / report。
4. UCL 不存在一个可以直接套用到所有 MSc dissertation 的统一字数 / 页数规则。
5. 如果 assessment 有 word count，具体 module instructions 必须说明：
   - figures；
   - tables；
   - appendices；
   - bibliographies / references；
   等是否计入。
6. 使用 GenAI 时，UCL 要求 acknowledgement，并说明如何使用；具体允许程度由 assessment instructions 决定。
7. 引用必须规范且一致，但目前没有公开证据表明 COMP0191 强制某一种 citation style。

### 仍不能确定

1. COMP0191 2025/26 的实际正文上限；
2. figures / tables / captions 的计数规则；
3. appendix 的计数及长度限制；
4. references 是否计入；
5. 强制模板与版式；
6. 是否必须在 PDF 中声明 word count；
7. COMP0191 专属 GenAI declaration 模板；
8. COMP0191 专属 citation style。

# 16. Bottom Line

现阶段最重要的不是去网上找一个“UCL MSc dissertation 通用模板”来套，而是拿到：

> **COMP0191 2025/26 assessment brief / dissertation guidance**

因为 UCL Academic Manual 自己已经明确把下面这些关键细节下放给具体 assessment：

- maximum length；
- included / excluded material；
- appendix；
- bibliography；
- formatting；
- referencing convention。

在拿到这个文件之前，任何具体字数、页数、appendix “无限”、references “不计”等数字性结论都不应写进提交计划。

而模块代码方面：

> **COMP0190 = Project Preparation**  
> **COMP0191 = AISD MSc Final Project / Dissertation**

当前官方 catalogue 对这一点已经高度明确；剩下只是通过 Portico 的 2025/26 Module Information Document 完成年度级最终确认。
