\section{Configuration pins}

\begin{itemize}
\item Step budget \texttt{max\_steps}~$=30$ for every condition; the base config
  default is aligned to the same value so that a config omitting the override
  cannot silently inflate cost by a third.
\item Decoding: \texttt{temperature}~$=0.0$, \texttt{do\_sample}~$=$~false,
  \texttt{max\_new\_tokens}~$=4096$, \texttt{seed}~$=42$.
\item Viewport $1280\times720$; post-action settle 0.5\,s so that the
  accessibility tree and screenshot describe the same stable page state.
\item Local model weights pinned by Hugging Face revision SHA recorded in the
  merged run configuration, so each run's metadata proves which weights loaded.
\item Energy: NVML sampling at 0.5\,s; carbon intensity 220\,g/kWh (UK grid
  average); electricity tariff \$0.12/kWh.
\end{itemize}

\section{Data integrity controls}

Three controls exist because their absence produced errors during this work, and
each converts a silent failure into a loud one.

\paragraph{Task-set SHA matching.} Every condition's sorted scored task-identifier
list is hashed; aggregators refuse a condition whose hash does not match the
cell's expected set. A partial run therefore fails loudly instead of producing a
smaller denominator.

\paragraph{Deduplicating record reader.} All JSONL reads pass through one loader
that removes restart duplicates and tolerates truncated trailing lines, so a
resumed run cannot double-count steps.

\paragraph{Provenance headers.} Every analysis artefact records its producing
script, capture timestamp, and whether it is gate-eligible or exploratory. The
drop-one artefact used in Table~\ref{tab:dropone} carries a
\texttt{NON\_PAPER\_GRADE} flag, which is surfaced in the main text rather than
dropped.

\section{Known limitations of the released artefacts}

The mechanistic-interpretability results collected during an earlier phase of
this project are \emph{not} released as evidence and are not cited anywhere in
this dissertation. An implementation defect invalidated both the positive and
negative conclusions in that layer; the affected cells were re-run but not
re-aggregated, and quoting any figure from them before re-aggregation would be
unsound. VisualWebArena shopping conditions are likewise archived but excluded
from analysis, because they predate several pipeline corrections and mixing them
with post-correction data would compare different measurement regimes.
