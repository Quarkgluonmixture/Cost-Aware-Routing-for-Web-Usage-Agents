# GPT 搜索端 prompt（复制粘贴用）

**建立日期**：2026-08-10 · 配合 [FIGURE_PLAN.md](FIGURE_PLAN.md) 使用

五个 prompt **互不依赖，可任意顺序发**。每个都内建三条防幻觉约束：
① 必须给可核验 ID（URL / arXiv ID / DOI）；② 必须自报证据等级；③ 末尾必须单列 `UNCERTAIN` 节。

**回来之后我怎么用**：

| Prompt | 解决什么 | 我拿到后的动作 |
|---|---|---|
| **P1** | ⛔ FIGURE_PLAN Stage B 的 blocker（页数/图数/appendix） | 填 Stage B；主文 17 张按预定割序动刀 |
| **P2** | F2 文献图谱素材 + Ch2 problem-first related work | **先用 arXiv API 逐个核存在性与方法**，再画图 |
| **P3** | F10b / F12 的方法学锚 | 把 defuse 从"我自己想的"升为"标准做法" |
| **P4** | F13 / F14 的图形式（我最不确定的两张） | 定形式后实现 |
| **P5** | A4 进主文还是 appendix + T14 红线怎么写 | 定 energy/CO₂e 措辞 |

⚠️ **P2/P3 回来的引文一律不直接采信**：`curl` arXiv API 核 `id_list` 与标题作者，WebSearch 当月索引滞后不算证据（项目既有规则）。

## P1 — UCL 毕设硬性格式要求 ⛔ blocker

> **注**：user 已走 AskUCL 官方渠道询问（2026-08-10）。本 prompt 是并行加速，
> **官方答复优先**；若两者冲突，以 AskUCL 答复为准。

```
你是帮我核实学位论文提交硬性规定的研究助理。请联网检索，不要凭常识回答。

背景：我是 UCL MSc "Artificial Intelligence for Sustainable Development" (AISD) 的学生，
正在写毕业论文（final project dissertation），2026-09-01 提交。

请查清以下每一项的**当前（2025/26 学年）**规定：

1. 正文长度上限（页数或字数，说明是哪一种）
2. 图（figures）和表（tables）是否计入长度上限
3. 附录（appendices）是否计入长度上限；附录有无数量或长度限制
4. 参考文献是否计入长度上限
5. 提交格式：是否有强制 LaTeX/Word 模板？字体、字号、行距、页边距有无规定
6. 是否要求声明 word count
7. 生成式 AI 使用声明（GenAI declaration）的具体要求与格式
8. 是否要求特定的引用格式

另外请顺带核实一件事：我看到两个模块代码，COMP0190 似乎是 "Project Preparation"，
而 final project / dissertation 本身可能是另一个代码（我听说是 COMP0191）。
请确认 AISD MSc 的 **final project 模块代码**到底是哪个，并给出出处。

输出格式——**一个表格**，每行一项：

| 项 | 具体规定 | 出处 URL | 出处发布/更新日期 | 证据等级 |

证据等级只能取这四个值：
- `A 官方明文-年度明确`（ucl.ac.uk 域，且文档明确写了 2025/26 或当前学年）
- `B 官方明文-年度不明`（ucl.ac.uk 域，但没写适用哪个学年）
- `C 官方但间接`（UCL 通用 Academic Manual 规定，非本项目专属）
- `D 第三方或推断`

硬性要求：
- **不要给"MSc 论文通常是 X 页"这种通用经验值**。我要的是我这个学位/模块的规定。
- 找不到就在表里写"公开资料未见"，并放进末尾 UNCERTAIN 节。**编一个数字比说不知道贵得多。**
- 如果找到的是往年（如 2023/24）版本，明确标出年份，不要当成当前规定。

最后单列一节 `UNCERTAIN`：列出你没找到的项、以及你认为需要我直接问系里/Moodle 的项。
```

## P2 — 文献图谱素材（F2 + Ch2）

```
你是帮我做文献综述结构化梳理的研究助理。请联网检索，只用你能给出可核验 ID 的文献。

我的研究问题（请完整读懂，后面每篇文献都要对着它定位）：

> Web agent（能看网页、选动作、在浏览器里执行、循环直到完成任务的 AI 系统）
> 每一步都要把当前页面"喂"给模型。喂的方式有便宜的（结构化文本，如 accessibility tree）
> 和昂贵的（带标注框的截图 + 完整结构文本）。
> 我问两件事：(1) 昂贵的那种在什么时候才真正必要？
> (2) 这个"何时"能不能用**决策前就拿得到的便宜信号**预测出来？

请按下面四个簇各给 5-8 篇代表作：

- **簇 1**：web agent / GUI agent 的页面表征方式本身
  （Set-of-Marks、accessibility tree、纯截图、DOM 序列化、多模态 web agent benchmark）
- **簇 2**：模型或模态层面的 routing 与 cascade
  （LLM router、model cascade、query routing、大小模型混合调度）
- **簇 3**：基于置信度的弃权 / 延迟决策 / 选择性预测
  （selective prediction、learning to defer、cascade 的置信度阈值）
- **簇 4**：cost-aware / adaptive inference
  （early exit、adaptive computation、token budget、推理成本-质量权衡）

每篇输出一行：

| 簇 | 标题 | 一作 | 年 | arXiv ID 或 DOI | 是否 peer-reviewed（会议/期刊名） | **它优化的是什么** | **因此它为什么不回答我的问题** |

最后两列是这份清单的全部价值所在，请认真写：
- "它优化的是什么" —— 一句话，说它的目标函数/决策变量到底是什么
- "为什么不回答我的问题" —— 一句话，指出它与"给定同一个 agent，这一步该喂哪种表征"之间的具体差距
  （例如：它换的是模型不是输入表征 / 它假设标签充足 / 它的信号需要先付全额推理成本）

**不要写摘要**。我不需要知道它做了什么，我需要知道它把哪一维当成了决策变量。

硬性要求：
- **每篇必须有 arXiv ID 或 DOI**。给不出 ID 的条目直接不要写进表里，放进 UNCERTAIN。
- **绝对不要编造 ID 或标题**。我会用 arXiv API 逐条核，编的会被当场发现。
- 如果某簇你只找到 3 篇有把握的，就给 3 篇，不要凑数。

最后两节：
1. `GAP`：读完这四簇，你认为这四簇的交叉处**具体缺什么**？用 2-3 句话写，
   写成能直接放进 related work 结尾的那种"因此本文……"的推导，不要写成清单。
2. `UNCERTAIN`：不确定的、给不出 ID 的、以及你怀疑自己记错的。
```

## P3 — 两条攻击的方法学锚（F10b + F12）

```
你是帮我找方法学标准做法与规范引文的研究助理。请联网检索，给可核验 ID。

我有两个负结果要写进论文，各自会被审稿人用一句话驳回。我需要知道
**领域内应对这两种驳回的标准做法叫什么、由哪篇文献确立**。

**问题 1：如何证明"多样性收益"不只是"多试了一次"？**

我的设定：有 6 种不同的输入配置（mode），每个任务用每种跑一遍。我发现
"最好的单一 mode + 某个额外 mode 的联合" 比 "最好的单一 mode" 高 1.7-3.3 个百分点。
审稿人会说：这可能只是采样两次的平凡后果（pass@2 效应），因为同一个 mode 跑两次
也会翻掉一些原本失败的任务。

我需要：
(a) pass@k 的标准定义与**无偏估计式**，以及确立它的那篇文献
(b) 领域内区分"真多样性收益"与"重复采样收益"的标准对照设计叫什么、怎么做
(c) 如果有专门讨论 "ensemble diversity vs resampling" 的方法学文献，给出来

**问题 2：如何区分"特征里没有信号"与"样本量不够"？**

我的设定：嵌套交叉验证下，分类器在 8 个数据格里没有一个能 Pareto 胜过一个平凡固定策略。
有的格只有 15-97 个正例。审稿人会说：这只是欠采样的平凡后果，不是"信号不存在"。

我需要：
(a) 用 learning curve 诊断这件事的标准做法（怎么画、怎么读）
(b) **"训练误差也差 ⇒ 特征无信号；只有 CV 误差差 ⇒ 只证明数据少"** ——
    这个判据在方法学文献里的标准表述是什么？出自哪里？
(c) 小样本下 nested CV 的已知偏差，以及 permutation test 用于分类器评估的规范引文
(d) 多重检验族大小（family size）该如何界定的规范说法——
    具体地：如果我在 8 个数据格上各跑一次同样的检验，Holm 校正的 m 应该是 8 吗？
    有没有文献讨论"族的边界怎么划"？

每条输出：

| 我的需求 | 标准做法/概念叫什么 | 确立它的文献 | arXiv ID 或 DOI | 一句话：它具体怎么做 |

硬性要求：
- 每条必须有可核验 ID（arXiv ID、DOI 均可——我知道有些经典方法学文献不在 arXiv）
- **不要编 ID**。我会逐条核。
- 问题 2 的 (b) 是我最需要的一条：我要的是**一个有出处的判据**，不是"你可以画个学习曲线看看"。

最后 `UNCERTAIN`：哪些是你凭印象说的、哪些确实没找到规范出处。
```

## P4 — negative-result 论文怎么把"没学到"画成图（F13 + F14）

```
你是帮我研究学术图表设计范式的助理。请联网检索具体论文，给可核验 ID。

我的论文核心结果是**负的**，而且我要把它画成图，这是我最没把握的部分。

两个负结果：
1. 在 8 个数据格上，学到的分类器**没有一个**能 Pareto 胜过一个平凡的固定策略
   （每格都有多个候选策略的 成功率×成本 两个坐标）
2. 失败的原因是**标签的产生率**：标签只在任务被解开时才诞生，而基础成功率只有 2-27%，
   所以 4/6 格根本没有足够标签训练分类器。这是个"漏斗在最后一级触底"的结构

请找 3-5 篇**公开可读**的论文（measurement study / reproducibility study /
negative result / "X doesn't work" 类，也可以是优秀的博硕士论文），
它们成功地把"方法不work"或"信号不存在"画成了有说服力的图。

每篇输出：

| 标题 | 年 | arXiv ID 或 DOI / 链接 | **第几张图** | **用了什么图形** | 它为什么有效（一句话） |

"用了什么图形"要具体：例如"每个数据集一行的 dot plot，把 baseline 画成竖直参考线，
所有方法的点都落在参考线左侧" —— 我要能直接照着做的描述，
**不要写"用了柱状图"这种没有信息量的话**。

然后回答两个具体设计问题：

Q1. 我的结果 1（8 格 × 多策略 × 二维成本-成功率，结论是"没有一个赢"）——
    在你找到的范式里，哪种图形最能让"没有一个赢"**一眼看出来**而不显得空洞？
    如果画成 8 个小 Pareto 平面，读者要看 8 次才能得出结论，这是我担心的问题。

Q2. 我的结果 2（漏斗式：任务总数 → 被解开的 → 有标签的 → 真正可训练的，最后一级触底）——
    有没有比 Sankey / funnel 更适合"最后一级触底"这个 takeaway 的图形？

最后 `UNCERTAIN`：你不确定图号或图形描述的条目，明确标出来（图号记错比没找到更糟）。
```

## P5 — token/cost → energy → CO₂e 的合规写法（A4 + T14）

```
你是帮我核实可持续性度量规范的研究助理。请联网检索，给可核验出处。

背景：我的学位是 UCL "AI for Sustainable Development" MSc，所以论文被期待
真正处理可持续性这一层，而不是提一句。我的论文测量 AI agent 的推理成本
（token 数、美元花费、延迟、GPU 能耗采样）。

我的顾虑很具体：**我不想把成本代理偷换成环境影响**。
"token 少了 30%" 不等于 "碳排少了 30%"，我需要知道这条界线的规范表述。

请查清：

1. 从 token / GPU-hour 推算能耗与 CO₂e 的**方法学规范**：
   有哪些被广泛引用的 methodology？各自需要哪些输入、做了哪些假设？
2. 电网碳强度（grid carbon intensity）的**公开数据源**有哪些？
   时间/地域分辨率如何？引用时的标准做法是什么？
3. 报告 ML 系统能耗/碳排的**现行规范或 checklist**（如果存在标准或规范性文件，请给出）
4. 关键：文献里怎么**明确区分** computational efficiency 与 environmental impact？
   有没有专门批评"把 FLOPs/token 当碳排代理"的论文？我需要一个可引用的表述。
5. 如果只做了 GPU 侧的能耗采样（没有 PUE、没有制造阶段、没有网络传输），
   规范做法是怎么声明这个边界的？有没有推荐的措辞？

输出格式：

| 问题 | 结论 | 出处（标题 + arXiv ID/DOI/URL） | 出处类型（论文/标准/工具文档/机构页） | 我该怎么引用它 |

最后请单独给我**两段可以直接改写进论文的措辞草稿**（英文）：
- 草稿 A：只有 GPU 能耗采样、没有 PUE/制造阶段时，如何诚实声明计量边界
- 草稿 B：如何在不夸大的前提下，把"推理成本下降"与"环境影响"联系起来
  —— 或者，如果规范的答案是"在我这种测量条件下不该把两者联系起来"，
  就直接告诉我这一点，并给出支持这个判断的出处。

硬性要求：不要给通用环保论述。我要的是**能引用的方法学出处**和**能照抄的边界声明措辞**。

最后 `UNCERTAIN`：不确定的项。
```

## 回来后的核验命令

```bash
# P2/P3/P4 的 arXiv ID 逐条核（存在性 + 标题作者是否对得上）
curl -s "http://export.arxiv.org/api/query?id_list=2401.12345,2305.67890" | grep -E "<title>|<name>|<published>"

# 核某篇是否真存在（按标题搜，防 ID 对但标题错）
curl -s "http://export.arxiv.org/api/query?search_query=ti:%22Set-of-Mark+Prompting%22&max_results=3" | grep -E "<title>|<id>"
```

⚠️ 用 arXiv API，**不要用 WebSearch 核**——当月索引滞后，"查无此文"可能是假阴性（项目既有规则）。
